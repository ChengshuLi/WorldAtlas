# Retained additive activation (#1632)

This is the activation successor to merged #1523 source introduction PR1621
(`b220e43f837ed1895f13956764214dfb921c7b6b`). It reuses the original pilot and
Alaska qualifications. It does not repeat source fitting or a world audit.

The complete retained ledger has 20 scope rows: 12 supported components across
seven targets, 141 staged native-cell contributions (7 pilot + 134 Alaska), and
eight unresolved/rejected rows. These are historical staged counts, not an
assertion about the currently selected bank or integrated repairs.

`retained-activation-inputs.json` pins the complete original registry and ledger.
`original-target-source-bindings.json` supplies explicit containing source paths;
its historical proposed-bank readback is not current selection authority.
`prepare-supported-rebind-plan.mjs` prepares the existing strict issued plan,
with whole scope, patch and predecessor pins. Final plans require the actual
selected Arctic successor. They use the existing `run-current-rebind.mjs`,
issuer, external supervisor and 28-code closure from the merged composition
packet; no second native acquisition API is introduced.

`assemble-supported-activation.mjs` authenticates one complete changed-bank
qualification through the existing trusted reader and emits the existing V2
ledger, delta and eight-key runtime envelope. Original component/policy rows
and exceptions remain literal. Complete retained source and qualification metadata
remain charged during authentication. Original pilot/Alaska repeatability evidence
is reused; an identical second current-bank execution is not required. Hashes flow from ledger to
effective reference to patch to envelope; ordinary committed output descriptors
and the existing six-key sidecar still need to be issued after real publication.
The assembler itself does not select a release.

`evaluate-native-candidates.mjs` reuses `nativeRuntimeIndex`,
`nativePolygonIntervals` and `combineNativeBatch`. Complete owner rows come from
the checker-owned `loadNativeRowTable` / `acquireNativeRows` /
`validateNativeRowCarry` APIs. Canonical entry requires the real selected
snapshot, 262166 literal latitudes, matching selected target owner identities,
and every complete candidate window. A window above 4096 rows refuses instead
of clipping or subdividing. The caller must admit serialized owner rows while
the compact private projection remains live.

`prepare-choiseul-native-inputs.mjs` authenticates the six retained GEO4 cases,
whole simplified source inverse, complete current target geometry and owner.
It prepares a diagnostic native evaluation only. Choiseul is not relabelled as
the pilot/Alaska policy. A zero native gap is distinct from water and repair;
positive cases need the demonstrated missing source-policy binding before any
activation and do not block supported pilot/Alaska delivery.

Current controls cover the real literal operator on small grids, private
snapshot/projection refusal, consequential input mutations, publication
boundary refusal and complete original metadata conservation. They do not
qualify a final selected-v9 cold run or a selected release. All earlier logs
remain preserved under the author cache.

Final execution waits for actual #1627 and #1593 delivery, then fresh whole
current code/runtime/input admission. Authenticate all affected rows plus the
60-row/141-cell Arctic predecessor; retain every old assignment. One genuinely
qualified current-bank result and ordinary output custody precede sidecar and
selection changes, followed by actual normal consumer/regression and queue
delivery. There is no activation or integrated repair claim yet.

The qualifier now uses one native base identity consistently and requires the
privately consumed prior additive view and its complete component/authority set
to be conserved. Forged-view refusals have passed; a genuine selected prior
positive remains part of the final consumer qualification. No new policy class
or certificate version is implied.

The static package bridge is a draft: it consumes the existing private selected
reader, publishes the four exact envelope assets, and emits the effective
reference through the existing runtime contract. Default-route and refusal
controls do not qualify an activated package. Its final V4 package execution
interface, inherited restoration metadata contribution, declared package input
roster and current executing closure must be bound after the Arctic merge.
