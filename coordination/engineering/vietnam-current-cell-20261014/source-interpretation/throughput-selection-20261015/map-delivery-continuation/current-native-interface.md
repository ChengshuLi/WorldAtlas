## Separate guards that a new positive input must preserve

1. **Identity/membership:** native owner roster must match original bounds-asset custody; target IDs/ordinals are unique and exact. Optional reconciliation reads accepted semantic lineage/world index/parts, verifies complete member sets and rejects ambiguous/direct-owner conflicts (`P:682–741`).
2. **Whole source and competitors:** complete catalogue family parts reassemble the original product and every original feature identity. Measured original geometry and selected canonical base must match; measured same-owner siblings retain their own vetoes and cannot be omitted to evade them (`P:823–888`).
3. **Positive physical coverage is separate from source domain:** `deriveSourceTargetNativeDelta` requires exact member-to-owner joins, then requires the centre in a target source polygon and in coverage from an active original member. Same-owner sibling coverage cannot be borrowed (`src/native-grid.js:226–249,269–282,339–350`).
4. **Negative guards:** existing ownership, exact source/coverage/exclusion boundary ties, competing owners, territorial exclusions, missing/extra reconstruction, actual land/water contradiction, hierarchy disagreement and mapped-L1 exterior remain withholding conditions (`src/native-grid.js:300–350`; `P:575–625,907–995`). Mapped inland water is an allowed positive class, not a universal exclusion.
5. **Current owner-zero is downstream:** authority evaluation deliberately scans empty owner rows only to establish the allowed source/coverage domain (`P:955–962`). Real selected rows reject any delta overlap at1730–1736; `applyAdditiveNativePatch` independently rejects replacement of an assigned cell at `src/effective-footprint.js:166–176`.
