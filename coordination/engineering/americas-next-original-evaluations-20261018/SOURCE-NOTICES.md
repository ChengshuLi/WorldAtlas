# Foreign-family source notice supplement

This supplement records the source and license fields in the retained administrative metadata for whole foreign-family context. These are transcriptions of the accepted metadata record, not new source research or an independent conclusion about rights. Retain the metadata and each original source notice with the family. The listed represented year, provider string, license string, and source links are recorded fields; update/build dates do not establish the source observation date. Do not treat one family's license as applying to another family.
