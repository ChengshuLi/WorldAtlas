## Controls

The focused suites exercise actual immutable Git pins and cold CLI finalization;
compact/full configuration equivalence; append-only package selection; canonical
original identity; missing or changed historical restoration; duplicate, foreign,
nonordinary or incomplete restoration; selected registry conservation; closed
consumed roles; flat output admission, preserved prior output trees, collisions,
symlinks, post-admission mutation, exact resume and shared preparation budgets.
The adjacent handoff/acquisition suite retains physical-alias acquisition and
its ordinary exact writer unchanged.

The added Git/CLI control first finalizes with originals at canonical candidate
paths, then removes one original at the package-baseline snapshot and restores
its literal bytes in a subsequent candidate commit. Its explicit restoration
snapshot succeeds without another output copy. Omitting that snapshot or using
a changed canonical original refuses before output creation and preserves the
existing original body.

Run the committed controls with a plain Node launch:

    NODE_OPTIONS='' NODE_PATH='' node --test test/delivery-handoff.test.mjs test/delivery-finalize-config.test.mjs test/delivery-registry-delta.test.mjs test/delivery-handoff-advance.test.mjs

`focused-tests.tap` is the actual test output. An earlier baseline attempt inherited
incompatible Node launch options and passed all but the evidence CLI test, which
refused with `Plain Node launch required`. The clean environment run is reported
separately; that environment refusal is not represented as a code failure or pass.

## Limits and preservation

No atlas, GIS, source, native qualification or country operational producer was
rerun. The retained NOR/GRC/Congo historical restoration configuration was inspected
by the prior audit but not replayed; its historical restoration commit was not
available locally. No country-specific handoff retry is claimed here.

All original scientific and completed repository evidence is preserved in Git.
The deleted tests concerned the deleted automatic-copy helper. Current finalize
uses flat metadata outputs and the existing explicit committed restoration
contract. Historical nested-output trees are never rewritten; a changed inventory
requires a fresh preparation vintage. The independent review and ordinary
serialized integration remain required. Production deployment is outside this
engineering change.
