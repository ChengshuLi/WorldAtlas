# Pending research preservation — not adopted map data

These four non-coordinate projections preserve researcher dispositions, unanswered questions, original holds, source identities and evidence pointers. They are historical PENDING research/planning records, not a new accepted map, qualification, authority, territorial determination or scientific credit. In particular, the MMR point plan is a plan: its class observations and adopted answers are empty.

Each record has its zero-based original row ordinal. The manifest binds each projection to the original whole-body SHA-256 and to the exact lossless gzip member in retained private Library artifact version 1. Those private originals—not these public projections—preserve all original coordinates and bytes. These projections cannot reconstruct omitted coordinates. The archive SHA/version is a custody reference, not public access permission; the private access identity is retained outside this publication.

All original rows remain, in order. One repeated answer phrase contained an explicit source-local row/column pair; that pair is replaced by a visible coordinate-omission marker. The surrounding interpretation is preserved and the manifest records the occurrence count. Explicit native keys/coordinates, source pixel/subpixel positions and original intervals have been omitted. Other fields and historical assertions are retained from their originals; field labels such as original_record_unchanged refer to that original historical claim, NOT byte equality of this redacted projection. Original key objects contain owner identity only and are not complete cell keys. Source IDs, scene/tile names and file/JSON pointers remain provenance identifiers, not newly published polygon arrays. Referenced observation/reviewer bodies are not included merely because their paths or hashes appear here.

Annual-source local paths are normalized to root-2026-10-13-task/; the private recovery record holds the original root. No absolute local username/home path is published.
