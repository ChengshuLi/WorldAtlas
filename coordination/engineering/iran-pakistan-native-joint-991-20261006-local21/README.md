This packet turns the retained shared-edge experiment into an immutable,
repeatable proposal generator. It changes no installed location, release,
canonical grid, application default, historical fact or production service.
Saravan and Panjgur remain the only proposed changed subjects. All eleven
original full-shape neighbors are retained for classification and comparison.

The generator reads original county OSM relation responses and staged original
Atlas neighbors at `06bf4087bf5aec0e7071830ba61e99105f2c3697`. The original
OpenStreetMap and contributors attribution and ODbL obligations remain applicable;
these responses are modern references with independent element edit timestamps,
not an official legal border or a common historical observation date. Source
authority, administrative identity mapping and dates are separately assessed in
#1115. Physical land/water remains unverified; this packet never labels the gap
water or infers political affiliation.

Exact binary-rational noding constructs one shared arrangement. Original owners
are preserved; an unowned face inside the retained component gets a proposed
subject only when exactly one named source covers its exact interior witness.
Unknown or multiply supported faces remain explicit. No buffer, snap, MakeValid,
nearest-owner assignment or positive-area cutoff is used.

The complete original areas of all eleven neighbors and the component reconstruct
exactly. Indexed noding agrees with an independent bounding-box-filtered reference
over all 6,109,260 segment pairs (9,103 intersecting bounding-box pairs). The
proposal has no lost exact face memberships, no new multiple face memberships
and no unknown component faces. Native Float64 polygons are valid, with every
exact original cycle, removed exact collinear vertex and rounded cycle preserved.
One exact-zero-area rounded walk per target remains explicitly recorded. Rounding
does change rational coordinates and can collapse continuous regions; it is a
derived cell representation, not replacement of the primary rational evidence.

The unchanged native map rule checks all 4,257,008 cells of the original full-shape
rectangle with its eleven neighbors. It removes 954 native unassigned cells,
loses no prior membership, creates no new multiply owned cell, and changes no
cell outside the native component mask. Native baseline, candidate and component
have no recorded cell-centre boundary ties in this rectangle. The older projected
rule removed 953 cells; these are distinct rules and their counts are not merged.
Original encoded-grid parity remains the already reviewed #993 evidence.

target cycles against native Float64 ownership across 1,592 rows per subject and
all 262,166 columns of each row using interval accounting. It finds zero differing
rows and zero exact intersection ties. Analytic controls exercise holes, nested

tiny positive features and zero-area rounded remnants. The existing native-grid
test suite separately passes eight tests, including an independent orientation
oracle and horizontal/vertex tie cases. Actual generator controls reject an
