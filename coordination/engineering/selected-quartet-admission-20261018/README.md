## Unified contract

`admitSelectedPackageDeclarations` in `scripts/package-inputs.mjs` is now the single definition-level predicate used by finalization, selected-data classification, and retained package transition admission.

- The old selector authenticates the exact prior sidecar body.
- Only its sidecar, runtime envelope, ledger, and patch can authorize removal.
- Removed paths must match the original ordinary-file mode and Git blob OID. Whole-pin/tree descriptors additionally bind their supplied size. Original source inventories intentionally contain only path/mode/OID; their Git OID already binds byte length, so no redundant body acquisition is introduced. Explicit invalid sizes never become an absent-size exemption.
- Unrelated declarations, relative order, optional inputs, verification paths and all other policy remain unchanged. Directory narrowing is forbidden.
- Current shared roles remain declared. Finalization protects its actual output/read paths; classification protects the current hook, envelope, registry and logical asset map; package reuse retains its complete current input inventory checks.
- The classifier also requires retired custody bytes to remain unchanged in the candidate tree. Retirement removes build declarations, not scientific history.
- Existing typed role reachability, new-file restrictions, complete source inventory, private execution capability, producer/runtime identity, output checks and geography gates remain independent requirements.
