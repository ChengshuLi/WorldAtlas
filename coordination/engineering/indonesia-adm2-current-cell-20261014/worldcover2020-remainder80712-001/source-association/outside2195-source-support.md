## What the original SID arrays mean

This is a general provenance meaning, not a new all80712 census. The pinned global queue README documents source-native coverage of the selected owner-zero cells from complete retained territorial products. The pinned `source-census-summary.json` describes source-covered owner-zero intervals, explicitly separating coverage from repair authority. Its retained independent review reconstructs source sweeps from raw per-feature intervals on sampled rows and checks that each SID array is the active source feature set and each owner array its lineage union.

The actual pinned `source-batch-intervals.mjs` reads those `source-candidates` runs, preserves their owner and SID arrays, intersects only the retained physical land/water support runs, and emits `physical-interpretation` when the candidate is unique but neither physical support mask covers it. Consequently `source-relative` here means **retained territorial source coverage outside retained physical support**, not absence of a territorial source. `raw-native-supported` in the roster is only numerical compatibility; the point coverage evidence comes from the frozen candidate interval, not that status label. The same documented meaning applies to original SID arrays elsewhere in this package; only the2195 keys were independently rejoined here.

The original full raster-generation source program was not located in this bounded review. The authenticated frozen outputs, actual extraction code and retained independent source-sweep review establish the retained-result semantics. They do not constitute a new independent geometric validation or a rerun of the original rasterization.
