## Why the display convention can apply, and why review remains necessary

At accepted cd68, `docs/DATA_SOURCES.md` describes partitioning shared interiors by supported Natural Earth reference borders, then finer source polygon and stable ID. `scripts/reconcile-topology.py` lines47-69 actually applies exclusive reference before the remaining-area fallback; the latter compares polygon area and stable ID. The policy does not encode a universal full-provider-over-original precedence rule.

These24 are genuine shared fine/territory interiors of unchanged source polygons. Choosing the IDN side therefore need not manufacture a fine source from a country mask. The existing original source remains the positive input, and the country reference is used only as the documented display discriminator. The proposal is to make that exact branch explicit for these observed combinations, preserving all negative source bodies and contacts, including the same-provider full-IDN outside result.

However, that outside result is consequential. The original retained input is explicitly the IDN `_simplified.geojson` variant at provider revision9469f09; the retained full body is a different geometry realization of the same519 identity records and claimed2020 edition. The provider describes simplified data as “less accurate, but much faster rendering.” [geoBoundaries simplified product documentation](https://www.geoboundaries.org/simplifiedDownloads.html). Its [API documentation](https://www.geoboundaries.org/api.html) exposes full and simplified GeoJSON separately. This is a reason to review and disclose the variant disagreement, not a reason to call original and full support equivalent. The reference convention establishes a display choice, not a factual assertion that the simplified border is geographically more accurate or a sovereignty judgment.

The recommendation is consequently bounded: accept the existing original-source branch for this exact24-key set if the project is continuing its original-source display convention, with the full-source outside observations explicit in the applicability evidence. If the reviewer instead requires concordant full-provider fine support, these24 remain held; the current evidence cannot honestly supply that missing concordance.
