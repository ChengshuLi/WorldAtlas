# Incremental original-source authentication

The worker still authenticates the exact original footprint digest. `src/native-source-digest.js` serializes sorted `[id, geometry]` pairs one at a time, with the same array brackets, commas, JSON representation and UTF-8 encoding as the retained whole-world method. Node's native SHA-256 comparison controls cover Unicode/lone surrogates, property order, unusual finite numeric representations, empty inputs, changed geometry and cancellation. Twelve digest/compiler/client/year-selection tests passed without skips. Two actual bundled-world worker controls matched every canonical row/run word and all original owner IDs; both reproduced the retained original footprint digest.

New dependency: exact `@noble/hashes` 2.0.1 with lockfile integrity. Only this dependency and its root entry are added; unrelated original lock entries are preserved. Its [upstream API](https://github.com/paulmillr/noble-hashes) supports incremental SHA-256 updates. This dependency replaces no geography source or authority and introduces no home-written cryptographic implementation.

Reproduction: use the explicit native candidate complete build documented in `../context-performance-v1/README.md`, then run `node test/native-world-context.mjs`. `ATLAS_NATIVE_CONTEXT_RECEIPT` selects the receipt path. `node coordination/engineering/native-grid-integration-1010-20261005-local17/source-digest-v1/diagnostic-world-check.mjs` additionally samples worker memory at progress/completion using a Node-only adapter; diagnostic sampling itself affects measurements. Both commands use the actual packaged worker with no browser, account or production access.

Verified source authentication covers 93,800,302 UTF-8 bytes, with largest single-feature chunk 923,945 bytes. This bounds transient serialization per feature; it is not a bound on total compiler memory. Plain measurements were approximately 6.02s and 9.26s ready, with raw whole-process peak-memory 2231376 and 1211760. The instrumented run measured approximately 6.59s ready, raw1375200. Large variability and different diagnostic overhead prevent a reliable whole-process memory or latency improvement claim. The worker input clone, original geometry objects, typed geometry and packed input/output grids remain substantial.

Limits: no production/mobile performance acceptance, factual topology approval, live content verification, database operation or deployment. Final bounded combined evidence, integration/release/recovery checks and independent exact-head review remain outstanding. Original tracked data was unchanged after this complete build.
