# Oceanian macro land coverage: issue #42

This read-only follow-up examines every one of the 64 named-land routes assigned to Oceania in the approved version-3 macro partition. It strengthens source coverage evidence; it does not approve regional interiors, import history, alter geographic identities, or deploy the Site.

All 64 routes received whole-polygon comparisons against full-resolution GSHHG 2.3.7. Thirty-nine suspect island or principal Hawaiian domains also received current OpenStreetMap coastline comparisons. The OSM extracts reconstruct 500 valid closed land rings, with zero missing source nodes and zero unclosed coastline chains. Candidate selection measures WGS84 ellipsoidal intersection against existing location land; it is not a centroid-only completeness claim.

Thirty-two named domains have current source coastlines wholly outside the existing footprints. Thirty are new named-land restoration candidates. The other two, Palmerston and Manihiki, require resolution of existing source identities before any geographic migration. Two source rings extend outside their query envelope and cannot qualify as confirmed omissions under this comparison.

A significant source mismatch is retained explicitly: current COK-4951, called Aitutaki, is physically on Manuae; current COK-4956, called Palmerston, is physically on Aitutaki. The actual Palmerston coast is absent. Preserve the original location IDs, geometry, and claims; do not silently relocate history or add duplicate named locations. Manihiki has an existing generalized outline that misses the modern coastal islets; it must not become 84 new locations.

GSHHG alone can produce false absence findings because old shorelines are displaced. Modern comparisons show existing Baker, Banaba, and Teraina land, despite little or zero GSHHG intersection. Do not automatically replace generalized coastal edges or import every unrepresented old-source component.

The source scope is finite. Bounty Islands, for example, measures about 2.77 square kilometres in GSHHG versus 0.502 square kilometres in the current OSM coastline union. This verifies missing named land and its fixed regional destination, but does not certify the precise complete modern physical shoreline. The global macro associations remain the approved conventions; local granularity and grid representation need their own gates.

`ledger.json` accounts for all 64 original routes, original provenance, outcomes, and source-identity exceptions. `report.json` holds full GSHHG component comparisons; `osm-report.json` holds current source ring topology, source versions, intersections, and coverage. `grouped-named-land-restoration-candidates.geojson.gz` stages entire named source territory unions without clipping islands into search rectangles. Its Palmerston/Manihiki entries are explicitly held. `osm-all-land-footprints.geojson.gz` includes all compared modern rings, while `osm-missing-land-candidates.geojson.gz` contains only omission candidates. Neither file is an imported geography release.

Original source bytes are retained as gzip files, with raw and stored hashes in the ledger and manifests. The 906 GSHHG headers and coordinate records are extracted byte for byte, in original source order, from the full binary release. `gshhg-extraction.json` pins the 118,617,033-byte upstream archive and its 95,809,336-byte full native member, so the entire archive need not be shipped as a website asset. LGPL v3 or later applies to GSHHG, ODbL 1.0 and attribution apply to OSM, and CC BY-SA 4.0 applies to Wikipedia text. Two authority URLs returned HTTP 200 error/homepage content; they are explicitly unusable geographic evidence.

To replay comparisons, use the exact input geography pinned in `ledger.json`, set `WORLDATLAS_REPO` to that checkout, and run `audit.py` followed by `osm_review.py` from this directory. Python dependencies are the repository's pinned numpy, shapely and pyproj packages. The byte-exact retained GSHHG subset and raw OSM XML suffice; no live Overpass request or mutable network source is required. Fetch helpers document the original requests but are not necessary for replay. A newer geometry release is a new audit input, not a reproduction of this checkpoint.

All candidate migrations must preserve exact predecessor geography and historical claims, verify parent chains and original fixed regional routes, and record grid visibility without arbitrary reassignment of water cells. These records do not open location-attribute imports or claim complete contemporary world shoreline coverage.
