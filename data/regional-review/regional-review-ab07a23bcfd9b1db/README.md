# Côte d’Ivoire interior review — issue #469

This is a source and semantic review of the issue’s exact 215 location IDs, 14 parent groups and partial Côte d’Ivoire area. It preserves the issue scope JSON as published, a source-only reproduction, row-level assessments and retained original source responses. It does not amend any location, boundary, hierarchy, approval, publication or historical data.

## Finding

The Atlas entries in this subset point to the exact 2021 `geoBoundaries` CIV ADM3 `shapeID`s, and their display names match after reversing a reproducible UTF-8-as-Latin-1 rendering artifact in the fetched GeoJSON string values. The pinned source metadata labels these 510 ADM3 shapes “Departments.” That role is contradicted by the official CNTIG/OCHA layer: its field schema names `admin3Name` “Sous-Prefecture” and `admin2Name` “Département.” The official DGAT describes 108 departments and 509 created sub-prefectures (475 open); the 2021 census and current CNTIG/OCHA geospatial service each report/contain 510 sub-prefecture units. Therefore all 215 reviewed entries are individually classified `correction-needed` for the source-role assertion. Their IDs and location names are supported by the pinned features; the finding does not establish that every current legal unit or boundary is correct.

Each of the 14 Atlas `framework:province` parents in this scope corresponds by name to an official regional group in the current CNTIG/OCHA service and a unique shape in the pinned 2016 geoBoundaries ADM2 layer, whose canonical type is regions. All 14 parent groupings are classified `justified` for that reference purpose, while their boundaries and regional interiors remain unapproved. The Atlas intentionally groups these ADM3 source units at the region parent, bypassing the official department tier. This is not evidence that the region is each sub-prefecture’s direct administrative parent. The official service supplies 213 unique source-name/region matches for the 215 entries. Two Guézon records share the same official `admin3Name` within Guemon, so their department-level assignments cannot be distinguished from names alone; both rows retain that uncertainty.

The owned area is partial: 215/510 location members and 14/33 direct region groups. The other source-ID workload cohorts are #468 (17 Côte d’Ivoire units), #470 (215) and #471 (63); `cohort-partition.json` preserves those exact issue rosters and the generator verifies that all four disjoint scopes equal the 510 Atlas CIV ADM3 IDs at the pinned baseline. That workload partition does not prove current legal coverage. The area’s baseline source is WGSRPD level 3, a 2001 botanical-country scheme for plant-distribution records. TDWG describes its level-3 units as approximately country-level and says some may ignore political factors. The parent name therefore does not independently prove a complete current Côte d’Ivoire sovereign boundary. The exact parent-area perimeter and its redistributed source license were not re-established here; the area is individually classified `insufficient-evidence`.

The official DGAT count is 509 created / 475 open sub-prefectures, while the retained 2021 geoBoundaries set and current CNTIG/OCHA service each contain 510. The definition and status of the one-unit difference have not been resolved. ANStat’s public API documentation exposes `cod_dep` and `cod_sp` but its documented 2021 endpoint reports 526 rows. The raw API response could not be obtained from this environment; no code-level crosswalk is asserted. These discrepancies require explicit follow-up rather than a count-based completeness claim.

## Exact sources and scope

`issue-scope.json` preserves the exact IDs, area/province IDs, release and geometry pins, and membership hash from #469. `cohort-partition.json` preserves the three other original issue snapshots used for the workload-only coverage comparison. `location-assessments.json` provides an individual classification for every ID and links it to its pinned shape ID and baseline containing file. `province-assessments.json` individually assesses all 14 parent groupings; `area-assessment.json` records the partial area limitation. `acceptance-screen.json` reports evidence and limits for each of the nine geography concerns in the issue acceptance. Its limited structural screens (nonempty names, one Polygon component and no interior rings) are not topology or completeness checks. City extents, official code-level completeness, island omissions, size outliers, full parentage and neighboring boundary consistency remain unverified. `reproduction.json` records source and baseline file hashes and the generated counts. `sources/` retains the lawful geoBoundaries 2016/2021 and CNTIG/OCHA official current layer files and metadata, with upstream URLs and attribution. `source-restoration.json` gives restoration instructions and actual captured hash where official web pages are not redistributed due to unclear reuse terms.

The pinned geoBoundaries inputs are from commit `9469f09`: 2021 CIV ADM3 (510 shapes; metadata canonical role “Departments”; CC BY 3.0 IGO), and 2016 CIV ADM1/ADM2 parent layers (14 and 33 shapes; CC BY 4.0). The official current layer was retrieved on 2026-10-05 from the CNTIG/OCHA ArcGIS service. Its metadata describes the reference period as 2018-08-06 through 2023-09-20, update date 2023-04-04 and last service data edit 2025-04-11; service fields explicitly map admin1 to administrative region, admin2 to department and admin3 to sub-prefecture. CNTIG attribution and the service’s CC BY for Intergovernmental Organisations statement are retained in the layer metadata.

Authoritative references inspected: [DGAT territorial organization](https://dgat.interieur.gouv.ci/creation-de-circonscriptions-administratives/), [CNTIG/OCHA sub-prefecture layer schema](https://services-eu1.arcgis.com/HApVBfqpU6uDawrd/ArcGIS/rest/services/SP/FeatureServer/14), [geoBoundaries API/release documentation](https://www.geoboundaries.org/api.html), and [TDWG WGSRPD standard page](https://www.tdwg.org/standards/wgsrpd/). TDWG states the WGSRPD Level-3 botanical-country purpose can ignore political factors. The ANStat API/code table and RGPH 2021 publication are recorded as restoration-only leads in `source-restoration.json`: the API response was not retrievable here, and the PDF host returned HTTP 403, so no raw-response hash is claimed for either.
