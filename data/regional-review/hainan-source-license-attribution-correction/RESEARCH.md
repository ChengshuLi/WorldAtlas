# Hainan source-license attribution correction (#1291)

Reviewed 2026-10-06 (America/Los_Angeles). This superseding source-attribution erratum applies only to the exact 18 frozen subjects from #1053 / #1071. It does not revise their identities, parent assessments, geometry findings, classifications, current boundaries, or any source/legal approval.

## Finding

At immutable #1071 merge `a762119a4926c927617dc2f85471b3b822cadc58`, the separate geoBoundaries metadata companion `source/geoBoundaries-CHN-ADM2-metaData.json` declares `boundaryLicense` as **Open Data Commons Public Domain Dedication and License (PDDL) v1.0**. The companion was not embedded in the corresponding GeoJSON. The GeoJSON has only `type`, `crs`, and `features` at the top level, and feature properties `shapeGroup`, `shapeID`, `shapeISO`, `shapeName`, and `shapeType`; none declares a license.

The upstream geoBoundaries GitHub API resolves the source path to commit `9469f09592ced973a3448cf66b6100b741b64c0d`. Its LFS pointer identifies the 1,101-byte metadata companion as SHA-256 `7f609da61c856d022a9bf83b35fb271d78ebb5855ad2c1cdff337e51acdec58a`, matching the exact retained bytes at #1071. The GeoJSON LFS pointer likewise matches its retained whole-file SHA-256 `2b68d8a808742fc6d7acd769584db960d8fc2c25b9f1d20e3e98c72e9f1c4d34`. The source repository commit is dated 2023-12-13 UTC and reports a 2017 reference year.

This establishes what the retained metadata companion says. It does **not** establish the underlying GeoJSON's license, a chain of title, the validity of a grant, or permission to reuse either source. The metadata's `licenseDetail`, `licenseSource`, and `boundarySourceURL` values use malformed `https//` locators, and the upstream provenance remains unresolved. We retain the original packet's unknown-rights classification and restoration route.
