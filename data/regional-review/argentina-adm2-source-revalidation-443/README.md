# Argentina ADM1 / ADM2 source and boundary revalidation

Research date: 2026-10-05 (America/Los_Angeles). Issue #944 exact scope: 214 direct `gb:ARG:ADM2` location IDs plus all 14 parent/province subjects carried in #443. This packet proposes evidence-backed engineering follow-ups. It does not change shared source registers, IDs, hierarchy, geometry, releases, publication state, or import history. It does not certify the Argentina region or any current legal boundary.

## Findings

### Upstream source identities, bytes, counts and roles

- At geoBoundaries commit `9469f09`, the GitHub Contents API LFS pointer for `geoBoundaries-ARG-ADM2.geojson` is 69,702,323 bytes and has LFS object SHA-256 `f35dae5a257302dea5bd1549ae135baf82e7ee7491918854c3db9bbdec890177`. The retained #443 gzip restores byte-for-byte to this object. Its 525 features have 525 unique `shapeID`s. The companion metadata declares `admUnitCount=526`; the one-unit discrepancy remains unexplained, and no missing 526th feature was identified. The 214 scoped source IDs and labels match exactly, as previously reproduced in #443. The packet retains the exact 214-feature extract with the original full object hash, archive hash, API pointer and a deterministic extraction command. The source describes a 2020 ADM2/departments vintage, with source data update 2023-01-19, build 2023-12-12 and CC BY 3.0 IGO terms.
- The geoBoundaries `geoBoundaries-ARG-ADM1.geojson` pointer at that commit identifies 201,505 bytes and restored SHA-256 `b5d13177b09ad3347b617a83252cc77bc985f3c70802d4d7a8b50d3fbe5adba6`. It has 23 features and 23 unique IDs; companion metadata agrees on the count and declares 2006 / Province / CC BY 2.5 Generic. The existing Atlas source register instead expects `7cc9b00b…`. That is a register-to-object identity conflict, not evidence that this upstream object is damaged. The 23 labels include “La Roja” and have no feature named “Entre Ríos”. The national current Georef province source has 24 features, including La Rioja and Entre Ríos.
- The 2006 “La Roja” feature has its largest area overlap with current Georef La Rioja: 95.11% of the current La Rioja polygon; old 2006 features collectively cover 99.93%. This supports a likely label error or alias, but it does not reveal why that spelling was published. The 2006 “Buenos Aires” feature covers 97.74% of the current Entre Ríos polygon; all old ADM1 features together cover 98.30%, yet none is named Entre Ríos. The source therefore omits a distinct Entre Ríos feature/label, while the geometry suggests much of that present-day territory was included under Buenos Aires. The historical legal lineage and intended treatment remain unresolved. The 2006 CABA feature covers only 32.30% of the current Georef CABA polygon, so the two vintages are not interchangeable.
- Official Datos Argentina publishes the Servicio de normalización de datos geográficos under CC BY 4.0 and describes it as built from IGN, BAHRA and INDEC data. Georef’s data model says the territorial-unit resources (provinces, departments and municipalities) are sourced from IGN. On 2026-10-05, full official department JSON and GeoJSON responses each contained 529 IDs/features, with source property `IGN`; categories were 379 `Departamento`, 135 `Partido` and 15 `Comuna`. The province GeoJSON contained the current 24 names. The exact responses and HTTP headers are retained. The responses do not declare a release version or legal effective date; department GeoJSON HTTP `Last-Modified` was 2026-08-19. Treat this as a lawful, current official comparison layer with recorded retrieval, source and vintage limits, not a legal adjudication or proof of every boundary.
- The 2017 IGN interdepartmental metadata describes a 1:100,000 layer and CC BY use. Its advertised geometry URL returned HTTP 404 on 2026-10-05, so this packet does not claim an IGN 2017 overlay. INDEC’s 2022 layer metadata says its license is not specified; no INDEC boundary geometry is redistributed.

### 214 exact ADM2 subjects and parents

- The 2020 geoBoundaries subset contains exactly the 214 requested native IDs; every source feature has one unique shape ID. Its prior label comparison is exact for all 214 source features. The current Georef release has 205 normalized-name candidates: 141 unique-name candidates and 64 subjects with duplicate-name candidates; nine old labels have no exact normalized current name. Names were not used alone to select a geometric match. The full per-ID sheet retains every positive-area current feature hit, including province, category, ID and area, so duplicated names and neighboring candidates stay visible.
- The equal-area screening maps 203 of 214 old features' largest current overlaps to the same normalized name. It maps 11 Buenos Aires matches as `Partido` and the remainder to `Departamento`. These are source-role observations, not a claim that these newer features legally supersede the 2020 features.
- Twelve direct Atlas parent assignments conflict with the strongest positive-area/current-source comparison: ten units currently under `Ciudad Autónoma de Buenos Aires` map to Buenos Aires Province parties (Vicente López, La Matanza, Morón, San Miguel, General San Martín, Ituzaingó, San Isidro, Lomas de Zamora, Hurlingham, Tres de Febrero); Tafí del Valle and Juan B. Alberdi are currently under Catamarca but map to Tucumán in the current Georef source. The first set intersects an existing, related but narrower city-aggregate review in #941. Each proposed parent correction still requires independent legal/official source review because the comparison layer contains material overlaps described below. No parent was edited here.
- The all-feature Georef overlay leaves less than 99% of the old 2020 footprint covered for 20 subjects. For four subjects, the largest single current candidate covers less than 90%: Vicente López (85.28%), General Manuel Belgrano (87.55%), Pomán (89.79%) and Itatí (73.99%; the leading current hit is San Luis del Palmar). These are priority discrepancy cases, not proof of a defect: the two vintages differ, and the source roles and overlaps matter. For 26 of 141 unique exact-name candidates, the candidate-to-old polygon symmetric difference exceeds 5%; the detailed per-subject results expose this screening threshold and do not infer whether a difference is a legal change, source defect or generalization.
- The 14-row parent ledger separately preserves exact Atlas parent IDs and duplicates. Both distinct CABA framework parents match the single current Georef CABA name/feature; the second is fed by a separate 17-member city aggregate in #443, so this is an identity/parent-model issue rather than a second CABA jurisdiction. The older ADM1 matching and geometry overlays are recorded independently.

### Gaps, overlaps, holes, neighbors, fragments and islands

- The 214 scoped 2020 source geometries are 208 Polygons and six MultiPolygons. They have 280 polygon components total, five interior rings (all within Itatí), no empty geometries, and no invalid 2020 subject geometry in the shared measurement check. A pairwise check found zero positive-area intersections above 1 m² among these 214 historical features; the reproducible header-only ledger is `findings/scoped-2020-internal-overlaps.csv`. This is a source-topology screening result only and does not prove the source is gap-free or that the 214 are nationally complete.
- All six multipart subjects are itemized down to component number, equal-area area and bounding box, holes, and intersecting current Georef features: San Cosme (6 components), Capital in Misiones (3), Ituzaingó (29), Itatí (22), General Paz (2), and Berón de Astrada (10). Some components are consistent with the Paraná river-island pattern noted in #443. Neither that inference nor the current Georef comparison independently establishes island ownership, omitted islands, exclaves or completeness. The five Itatí holes have recorded bounds; no hole is silently removed.
- The official current Georef department geometry contains 484 distinct positive-area intersections between feature pairs within the 214 reviewed 2020 footprints; 446 intersect at least one hectare there. Of those pairs, 454 are Departamento/Departamento, 24 Partido/Partido and six Comuna/Partido. The areas are intersections between two distinct current Georef polygons clipped to the combined issue footprints, not intersections with the old polygon boundary. This is a substantial topology limitation in the comparison layer itself; it prevents treating the 529-feature layer as a clean planar partition. The rows identify every pair and affected 2020 subject. The single invalid current department geometry is “Islas del Atlántico Sur”, outside the 214 scope; it is reported rather than repaired. No automatic MakeValid, snapping, gap fill, sliver deletion or boundary repair was used.
- The full overlay ledger reports all neighboring current features with positive-area intersections above 1 m², not just a nearest-name match. A positive-area hit can reflect source overlap or a vintage boundary shift; edge-only contacts are controlled separately. Twenty 2020 subjects have under 99% coverage by the union of all intersecting current Georef features. The packet does not promote counts, joins, geometry validity or overlays into a completeness/correctness certificate.
