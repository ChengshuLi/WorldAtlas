## Finding

The Census Bureau's 2025 TIGER/Line technical material describes counties and equivalent entities as primary state divisions for Census data, recognizes Louisiana parishes at that tier, and identifies them with state and three-character county codes. The issue's three state parents therefore have a suitable current county-equivalent child tier. Census's published Division 7 membership is Arkansas, Louisiana, Oklahoma and Texas. The 2026 TIGERweb state-layer response independently reports Region 3 / Division 7 for all four states; child GEOID state prefixes match all 216 relevant state parents. This supports the current semantic tier, names, and parent-code association; it does not validate Atlas boundaries or their 2018 history.

The source lineage is not fully resolved. The exact GeoBoundaries file at the pinned commit returns 3,233 features and matches every scoped source ID, original ID and name, but its SHA-256 is `81fdd384…8647f43`; `data/administrative-sources.json` gives `16249e8d…6641a` for the same `gjDownloadURL`. The meaning of the catalog hash and whether it refers to another serialized artifact remain unknown. GeoBoundaries calls the source 2018, identifies Census MAF/TIGER as its upstream, and lists public domain, but that description alone does not identify which Census product / cartographic treatment created each retained shape.

A reproducible name/state crosswalk against official TIGERweb (layer metadata says January 1, 2026 vintage) uniquely matched all 216 IDs to 216 unique GEOIDs: Arkansas 75, Louisiana 64, Oklahoma 77. Every GEOID's first two digits agree with the framework state parent. Parent and membership counts are a cross-check, not geographic correctness evidence.

All 216 features are valid polygonal geometries in the retained baseline, the exact raw GeoBoundaries file and Census TIGERweb response. The Atlas and raw-source coordinate structures differ for every row; equal-area screen IoU ranges 0.98305974–0.99976855 (mean 0.99637444), with 15 under 0.99. This suggests the Atlas shapes were processed, but the issue evidence does not establish whether the processing was simplification, rounding, or another operation. Per-ID raw-source-to-Atlas differences are recorded separately from the current-vintage comparison. Eight baseline features are multipart (Terrebonne, Plaquemines, West Feliciana, Lafourche, St. Martin, Madison, St. Bernard, Iberia); disconnected parts may be valid county islands or water/coastal components and are not intrinsically defects. The comparison in `county-assessments.jsonl` separately compares Atlas geometry with raw 2018 GeoBoundaries and with Census TIGERweb 2026, using EPSG:4326 coordinate order without repairs, transforms to EPSG:5070, and measures intersection-over-union and symmetric difference. Thirty seven units fall below 0.98 IoU; eight high-difference coastal units (Cameron, Iberia, Lafourche, Plaquemines, St. Bernard, St. Mary, Terrebonne, Vermilion) are specifically flagged for source-history follow-up. A nine-county Census 2025 excerpt checks eight relevant coastal counties plus Arkansas County as a noncoastal control. TIGERweb and 2025 archive geometries overlap at IoU >= 0.999999997 in the eight shared sample records. The coastal sample covers Cameron, Iberia, Lafourche, Plaquemines, St. Bernard, St. Mary, Terrebonne and Vermilion. These large area signals are real differences between the retained 2018 GeoBoundaries-derived Atlas geometry and the Census reference geometry, but they do not tell whether lines reflect legal changes, cartographic treatment, water inclusion, simplification, or a source construction issue. Census cautions that TIGER depictions for statistical use do not decide jurisdiction or ownership and are not legal land descriptions. No boundary correction is proposed without dated county-change/source evidence.

Individual assessments classify all 216 as **insufficient-evidence** for full boundary/source correctness. Each row separately records the independently justified current county-equivalent identity and parent codes, the source pair, measurements, geometry signal, and a reason for the overall classification. This is a source-lineage hold, not a finding that all counties are wrong. No countrywide completeness claim is inferred from count agreement.

## Semantic / neighboring checks

- **Tier meaning:** The 2018 inputs are listed as counties; present-day Census records recognize county-equivalent units. Louisiana's 64 entries are parishes; this is a state-specific county-equivalent convention, not a repeated administrative tier. The other 152 owned units map to named counties.
- **Fragmented city territories / equivalents:** Census's 2025 county-equivalent list identifies Louisiana parishes, but lists independent cities as county equivalents for other named states, not these three. No independent city/city-county candidate appears in the exact 216-code query. This is limited to the county-equivalent layer, not cities at lower tiers.
- **Province-sized locations / anonymous remainders:** Each scoped location is one named current county/parish code and has a unique state-qualified GEOID. No anonymous remainder appears in this queried tier. No size-only inference is used to split or elevate an entity.
- **Disconnected territories / omitted islands:** Eight retained Atlas polygons are multipart; every shape is valid and each joins one Census county GEOID. The 2025 Census source sample confirms eight notable coastal geometries against TIGERweb. The 2018 provenance mismatch prevents a definitive omitted-island/fragment explanation; exact affected IDs and areas remain in the JSONL for follow-up.
- **Repeated tiers / weak parents:** All children have one existing state parent, and every state prefix matches its Census GEOID. This supports a code-level relationship, not a geometry containment/legal-boundary determination. No source or parent mutation is proposed.
- **Oversized groups / neighboring granularity:** County is Census's named county-equivalent tier in these states. State populations/areas vary, but no area threshold is used as a semantic tier rule. The division has four state members; #432 owns three and #431 owns Texas. No comparison beyond this official grouping and ownership handoff is made.

## Methods and reproduction

Run from the repository root with the project's pinned Shapely and pyproj environment:

```sh
python data/regional-review/regional-review-6fce33d53fdff81e/compare_counties.py
```

The script verifies source-file hashes, extracts the 216 issue IDs from the checked-out baseline, checks each original source ID/name/type, matches by exact case-folded county name plus state FIPS, verifies unique GEOIDs and state prefixes, requires valid unmodified geometries, and emits separate raw-source and current-reference comparison rows. The negative control confirms `Lafayette` alone is ambiguous across Louisiana GEOID 22055 and Arkansas GEOID 05073. Nine sampled 2025 geometries (eight coastal follow-up targets plus Arkansas County as a noncoastal control) are compared to archived 2026 TIGERweb features. There are no name aliases in the 216 joins. A wrong-state control fails because every lookup includes the two-digit state FIPS; duplicate/missing name-control rows fail its exactly-one assertion. The result is a comparison screen, not a legal boundary adjudication or certification.

Primary citations and exact retrieval receipts/hashes are in `source-inventory.json`. Sources are official Census products/APIs and the pinned GeoBoundaries original, not the user's browser. The 2025 technical PDF and 2025 excerpt are retained. The national 2025 zip (83,989,800 bytes) is preserved outside the checkout at the restoration path in the inventory; its exact upstream URL and SHA-256 are recorded there.
