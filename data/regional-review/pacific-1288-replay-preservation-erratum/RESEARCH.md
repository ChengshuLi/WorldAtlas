# Pacific replay preservation research

Issue #1463 isolates a reproducibility and custody failure in the old #1288 replay producer. Its fixed output root accepts no fresh destination and the actual #1288 command overwrites pre-existing reports and receipts. The source defect was independently reproduced by running the byte-identical #1288 producer from merge `7962b56b08e21c581b5d4034fe3616da5f87efd7` in three disposable, complete packet mirrors. In the third mirror, each of the three exact issue markers was replaced by the producer. The historical working packet remained unchanged.

## Frozen geographic scope

The replay scope is exactly 23 native identities: 11 Cook Islands records (`COK-4950` through `COK-4956`, plus `COK-4959` through `COK-4962`); five French Polynesia records (`PYF-4963` through `PYF-4967`); Pitcairn group record `PCN+00?`; four U.S. Minor Outlying Islands records (`UMI-5171` through `UMI-5173` and `UMI-5178`); geoBoundaries Chile ADM3 record `gb:CHL:ADM3:31580391B33082267781919`; and geoBoundaries Kiribati ADM1 record `gb:KIR:ADM1:97431129B35506555718846`. The frozen validator also checks 23 parent assessment rows and 10 area rows. These are retained packet relationships; they are not re-established as current authoritative administrative relationships by this replay.

The source vintage and neighboring granularity remain as documented in the original #405 packet: Natural Earth 1:10m Admin 1 (2022-06-02) is a generalized comparator; the retained Chile feature is geoBoundaries ADM3 source vintage 2020; the Kiribati ADM1 feature is geoBoundaries source vintage 2017 with OSM/Wambacher attribution. Official Cook Islands shipping, French Polynesia planning and maritime, UNESCO, U.S. Fish and Wildlife, Kiribati NSO and meteorological sources provide limited service/legal/physical context. Their retained packet descriptions do not establish complete island coverage, current boundaries, or equivalence between physical groups and administrative areas.

## Reproduction findings

The accepted successor is `replay-20261008-07`. It verifies the 94 exact input objects at their declared original commits: #1288 merge `7962b56`, #1054 merge `249e396`, and baseline/helper commit `a57085b`. The shared `NewVintage` safeguard pre-admits the complete output set before it creates scratch mirrors or runs the original code. Three full historical CLI executions ran in separate mirrors; each valid verifier run in each of the two run directories reproduced all three original report files exactly, including the marker scenario. The unchanged producer was also run against the issue's three private marker files and replaced each, confirming the actual overwrite. All 46 files in each original erratum packet mirror retained their source bytes and executable modes at the end of each test. The exact per-path hashes/modes, process return codes, complete stdout/stderr bytes, all 18 report files, producer receipts, scope/crosswalk fixtures, and directed-control artifacts are retained in the vintage bundle. The exact safe-runner source hash and both Python/runtime versions are included in the run summary.

The runner now captures all actual runner/verifier streams into memory before checking a historical producer return code. If that command fails, it publishes a hash-bound `replay-summary.json` with `status: replay_failed_after_capturing_actual_attempt` and the raw streams before returning a failure exit status. It deletes private mirrors only after a durable vintage publication; if publication fails, it prints and retains the scratch path for recovery rather than deleting captured evidence. The follow-up run `replay-20261008-08` captures and hashes the attempted child process, but it exited 1 because the available host Python 3.7 environment lacks the pinned Shapely dependency. Its `replay-summary.json` explicitly marks this as a failed attempt; it is not acceptance evidence. The accepted evidence remains `-07`.

The original frozen-scope validator command was exercised as a subprocess twice on valid input and once on each of nine malformed controls. The valid runs report raw/unique counts of 23, 23 parent rows, and 10 area rows. Each malformed command returned status 1. Separate file/directory, partial conflict, live/broken symlink, and traversal destination cases were rejected by `NewVintage` without changing their existing sentinel bytes. Preliminary output vintages `replay-20261008` and `replay-20261008-02` are retained as history but are superseded: their first inventory implementation attributed some multi-commit inputs to the wrong commit, so they are not used to support the accepted results. They are not overwritten by the corrected vintage.

These results establish process execution, output identity, and preservation behavior only. They do not approve geography, adjudicate administrative meaning, or prove the completeness or legality of any underlying source. No sources were downloaded in this follow-up. Source restoration, licensing, dates, and unresolved factual limits remain in `SOURCES.md` and the original packet. Vintages `replay-20261008` and `replay-20261008-02` predate exact multi-commit inventory checks; `replay-20261008-03` has those checks but lacks the marker-case raw report bytes; `replay-20261008-04` retains the marker reports but not both clean-run report sets; `replay-20261008-05` retains every report but omits generated producer receipts/control fixtures; `replay-20261008-06` retains the complete attempts but does not bind the runner's own exact code hash/runtime in its receipt. They remain preserved as intermediate attempts and are superseded by `replay-20261008-07` for acceptance evidence.

Source reconciliation and neighboring granularity remain with separate follow-ups #1052, #1058, #1059, #1060, #1061, and #611.
