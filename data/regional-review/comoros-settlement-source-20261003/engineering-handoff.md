# Source-owner handoff (not an authorization or access request)

**Next owner:** Main / authorized Comoros source liaison.

The public INSEED NADA catalog establishes a current official source lead, but its license and metadata are not sufficient to use the underlying microdata in WorldAtlas. Ask INSEED to identify or publish a non-sensitive and redistributable village/locality reference with:

1. source release and validity dates, stable locality and parent codes, all parent name/code fields, and a crosswalk to the retained OCHA 2019 ADM2/ADM3 units;
2. coordinates tied to the locality itself (not a sampled household, concession, village chief or market), coordinate accuracy and datum, or authoritative generalized locality geometry;
3. an explicit completeness statement for inhabited and named settlements, administrative remainder units, duplicate/local names and each island/outer-island component;
4. written license/redistribution terms for the exact output intended for Atlas.

For RGA-2 specifically, clarify what is meant by community coordinates versus aggregated geographic identifiers, which rows are exposed, whether all locality records are represented, and whether a public non-sensitive derivative exists. Do not request, download, retain or redistribute restricted microdata as part of this handoff. No message has been sent to INSEED.

The crosswalk in this packet only reproduces source administrative parent relationships. It does not join settlement names, prove legal administrative authority, or grant physical-land completeness. Keep Mayotte's political status separate from island/coast observations.
