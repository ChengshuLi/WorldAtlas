## Reproduction and controls

Run from the repository root with Node 24 and Python 3.12/Shapely 2.1.2:

```sh
node data/regional-review/south-china-sar-source-lineage/reproduce-lineage.mjs
```

The script reads exact baseline feature bytes from the pinned Git commit, the immutable Natural Earth DBF/SHP/SHX records and the immutable geoBoundaries GeoJSON, and the retained current HKG district GeoJSON. It writes `lineage-results.json`. Positive controls prove the exact 18-ID HKG join and one-to-one Macao ShapeID join. Negative controls replace a member with a non-existent sentinel and verify rejection/zero matches. Two runs produced identical result SHA-256 `0a1b14f915bba2afa7a77cd0226d942254525f1ff71835f6065342d4f56f8fd9`. The output hashes identify source/Atlas coordinate arrays and envelopes; these are identity/byte measurements, not topology proofs. Run `python3 data/regional-review/south-china-sar-source-lineage/reproduce-original-union.py` to replay the historical union transformation for both subjects. The script compares validity, topology, symmetric difference and Hausdorff distance against the exact baseline features. It writes `original-union-results.json`; the result records the historical code and source hashes, runtime, and the untracked-input limitation. The replay code follows the original shapefile polygon ring orientation when rebuilding polygons, then applies the recorded make-valid/union sequence. Its results are reproduced from the retained upstream source package and are not asserted byte-identical to the unavailable historical cache.

The historical aggregation script is pinned at commit `4bdba3d40acc2d725e4aeb54c3b9aab559a91469`, exact SHA-256 `ac18022fa1c881bdbedc590f150a501ad23d52ba86cb47c5a005643012f1ad1a`. Its `merge()` operation is `polygon(make_valid(union_all(...)))`; it explicitly identifies the unnamed geoBoundaries Macao input by ShapeID and records the Natural Earth/geoBoundaries crosswalk. The pre-aggregation `data/.cache/semantic/input.geojson` was untracked and is absent from the parent commit, so exact historical input bytes cannot be verified. The bounded replay below uses retained Natural Earth SHP/SHX/DBF and geoBoundaries 2017 bytes. It yields valid unions but does not topologically equal the baseline Atlas geometries: HKG symmetric difference is 0.003352914582248336 square degrees (Hausdorff distance 0.02103014569054354 degrees); MAC is 0.0006902633571228161 square degrees (Hausdorff distance 0.01807680577530709 degrees). This shows the original source snapshot, prior simplification/generalization, or further transformation remains unresolved; it does not establish which caused the difference. No full official boundary comparison or current legally reusable Macao vector was recovered.
