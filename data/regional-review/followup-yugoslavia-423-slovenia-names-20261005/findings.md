# Slovenia 2017 municipality-name follow-up (#1016)

Research captured 2026-10-05 UTC from fresh main `3042d1278e87dae00c26924c339e940c9fba240e`.

## Finding

The 53 candidate IDs and Atlas names occur in fresh-main `data/geography/part-22.json`. Their 53 municipality codes, current GURS names and per-feature source dates match the original current GURS municipal polygon file and provenance retained by #423. Each code also has non-null municipality-area observations in SURS table 0214809S at both reference dates 2017-01-01 (`2017H1`) and 2017-07-01 (`2017H2`), supporting presence of those codes in the contemporaneous series. The API exposes one municipality label per code in a static dimension; it does not provide a name history by half-year. The page says the table covers 2004H2–2018H2 and was last updated 24 January 2022. Thus the labels retrieved now, even where they match current GURS spellings, do not establish the official names effective in 2017.

The SURS release dated 2017-07-18 confirms that the GURS Register of Spatial Units recorded 212 municipalities on 2017-07-01, but publishes only aggregate counts in the article. It cannot independently validate each of these 53 historical spellings. The candidate packet's current-GURS name/code fields are current crosswalk evidence only. Slovenia's Cadastral Real Estate Records Act (ZKN), Article 130, limits access to RPE historical data to authorized geodetic professionals and state bodies; copies of RPE documentary records may be requested by anyone who demonstrates legal interest through a reasoned written request. No qualifying access route was established in this research. No name correction is proposed and all 53 historical-name findings remain unresolved.

## Per-ID reproducible assessment

`2017-name-assessment.csv` lists every exact issue subject ID, geoBoundaries source shape ID, current GURS municipality code/name from the pinned candidate ledger, SURS's current static-dimension label, and non-null 2017H1/H2 area values. `reproduction/reproduce-sistat-2017-roster.py` performs the join by municipality code and asserts the exact 53 unique IDs, all code matches, and both dated time-series values. This is an identity/presence check; area values are not boundary/name proof.

The Atlas candidate strings include diacritic/encoding-looking forms (`Ckocjan`, `Ajdovtcina`, `Gelezniki`) as well as apparent substitutions/truncations (`Sveti Tomaa`, `Velike La`). The current official labels differ, but the observed character pattern alone cannot classify these as transliteration, a 2017 official name, or an Atlas source defect. Each row is therefore explicitly unresolved instead of inferred from normalization.

## Source, license and restoration request

- SURS SiStat table 0214809S: `https://pxweb.stat.si/SiStatData/pxweb/en/Data/-/0214809S.px`; API: `https://pxweb.stat.si/SiStatData/api/v1/en/Data/0214809S.px`. Table metadata names SURS and SMA as sources and says the municipality classification is SKTE 5. Retrieved API response and exact JSON request are retained under `source/`. SURS copyright terms release its statistical data for unrestricted reuse with required attribution to SURS; retain attribution and identify derived tables as our assessment. The retained response is not the historical name ledger.
- SURS 2017-07-01 release: `https://www.stat.si/StatWeb/News/Index/6776`. It supports the dated national count and explains that the register is maintained by GURS; it has no full municipality-name roster.
- Slovenia's Cadastral Real Estate Records Act (ZKN), Article 130: `https://pisrs.si/Pis.web/pregledPredpisa?d-49687-s=1&id=ZAKO7952` (also Official Gazette 54/2021 at `https://www.uradni-list.si/glasilo-uradni-list-rs/vsebina?urlurid=20062024`). Historical RPE data are accessible to authorized geodetic professionals and state bodies; any person may request inspection/copy of the RPE collection-of-documents records only by demonstrating legal interest in a reasoned written request. This is the access restriction behind the restoration request.
- GOV.SI GURS evidence description: `https://www.gov.si/teme/nepremicninske-evidence/`. It states that the Register of Spatial Units stores unit type, code, name, area and a permanently retained collection of documents, kept in physical and electronic form. This makes the historical archive the authoritative restoration path.
- SURS reuse terms: `https://www.stat.si/StatWeb/StaticPages/Index/Copyright`.

## Limits and handoff

The name evidence is blocked on legally restricted historical RPE records, whose request and restoration route are listed per code in the ledger. It does not prove polygon completeness/equivalence, settle neighbor granularity, correct names, approve a region, or authorize publication/import.
