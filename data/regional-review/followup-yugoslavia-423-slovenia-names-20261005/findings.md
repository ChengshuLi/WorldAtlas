# Slovenia 2017 municipality-name follow-up (#1016)

Research captured 2026-10-05 UTC from fresh main `3042d1278e87dae00c26924c339e940c9fba240e`. The 53 exact candidate IDs and release pins are unchanged from #423.

## Finding

GURS's official historical municipality WFS (`SI.GURS.RPE:OBCINE_H`) resolves both required dates, 2017-01-01 and 2017-07-01, for all 53 codes. The response contains 899 historical/current records across the requested codes. Applying the service's `DATUM_OD`/`DATUM_DO` validity intervals yields exactly one municipality-name feature per code at each date. All 53 names are stable between the two dates. `NAZIV_DJ` is null throughout the retained records. All 53 currently pinned GURS names also match the historical names at both dates, while none of the 53 Atlas reference strings matches the official Slovene name.

This is date-specific authoritative name evidence. It supersedes the earlier claim that historical RPE names were restricted to authorized professionals/state bodies. That reading of ZKN Article 130 was wrong: paragraph 2 gives everyone access to historical RPE data subject to Articles 126–128, and paragraph 4 says those records have been available through IS Kataster since 2022-04-04. Paragraph 3 separately gives authorized professionals/state bodies a right to request access to the collection of documents and historic copies. GURS also publicly announced the RPE history/change WFS on 2024-01-11 and states that municipalities have their full history migrated. The public WFS request succeeded without registration.

All 53 Atlas strings differ from the official 2017 Slovene names, often by base-letter substitutions or truncation (for example, `Ckocjan` vs `Škocjan`, `Kalovci` vs `Šalovci`, and `Gelezniki` vs `Železniki`). These are not safely described as simple diacritic removal or standard transliteration. The upstream Atlas string-generation/locale policy is not in this packet, so the packet does not assert a specific corruption mechanism. The engineering handoff recommends, if official Slovene is the intended display name, replacing each 2017 reference spelling with the dated GURS name while retaining stable IDs and preserving prior strings as alias/provenance until source lineage is checked. It does not edit shared geography or decide product locale policy.

## Per-ID reproducible assessment

`2017-name-assessment.csv` preserves each exact issue ID, source shape ID, Atlas reference name, leading-zero municipality code, current GURS crosswalk label, SURS 2017H1/H2 area pair, GURS official names effective on both requested dates, and the corresponding GURS feature IDs. The reproducer joins SURS by municipality code, joins GURS history by `SIFRA`, applies `DATUM_OD <= date < DATUM_DO` (with an open-ended end allowed), asserts exactly one effective feature per subject/date, and produces the findings and summary. It confirms 53/53 Atlas IDs/names against pinned fresh-main features and 53/53 candidate current GURS code/name/date rows against the retained #423 GURS source.

The WFS historical dataset is not the same thing as a dated source boundary reconstruction. Its feature geometry was deliberately omitted from the response; the evidence supports official names and validity periods only. It does not establish geometry completeness/equivalence, the location's territorial parent, neighboring granularity, or a regional approval. SURS area values only corroborate dated series presence and are not boundary proof.
