## Findings

`assessment.json` records all 230 subjects individually, their pinned Atlas parent, source feature and administrative level, source role/year/license as recorded, geometry structure, and a representative-point screen against the corresponding retained source parent polygons. Classification is deliberately conservative: 17 Chad ecological fragments are **correction-needed** for a metadata lineage mismatch; the remaining 213 are **insufficient-evidence**, because one source snapshot does not prove current legal units, complete coverage, or correct full-polygon parentage. None is marked justified. The single apparent source-parent name disagreement (Wayi: current Atlas parent slug `lac`, point falls in pinned source parent `Hadjer-Lamis`) is a flag for exact boundary/vintage crosswalk, not a parent correction; a point screen is not a polygon overlay.

The 17 Chad physical portions map to five retained RESOLVE features (ECO_ID 53, 822, 823, 842 and 844). ArcGIS item, layer and query responses identify the product as **RESOLVE Ecoregions and Biomes**, “Biomes and Ecoregions 2017”; selected features report `CC-BY 4.0`. Atlas metadata currently records their `source_role` as `Departments` and their selection rationale as administrative. This is a high-confidence source-role/selection-rationale mismatch. It does not show that any clipped portion is complete, correctly clipped, or belongs at this Atlas tier. Do not change the IDs, source members, geometries, or parents on this evidence alone. Create a bounded source-role correction handoff for these exact 17 IDs, coordinated with the original administrative predecessor-source licenses.

An additional aggregate check identifies six 2019 TCD ADM2 source units represented only by these 17 ecological portions, with no direct administrative Atlas member: Tibesti Ouest (4 portions), Tibesti Est (3), Am-Djarass (3), Fada (3), Borkou Yala (2) and Borkou (2). The union of each source unit's portions covers 99.6833%–99.9988% of that original feature by planar EPSG:4326 area ratio; the exact fractions and IDs are in `geometry-audit.json`. This is strong evidence that the fragments collectively derive from and nearly partition those six predecessor geometries. It does not establish legal/current territorial extent, geodesic area, or that ecological portions are the correct final atlas units. Engineering handoff should preserve the source-to-fragment lineage and distinguish the six predecessor departments from the seventeen physical features.

The administrative groups have distinct evidence gaps:

* **Central African Republic:** the retained 2018 geoBoundaries source is “Municipalities” / “Communes,” 175 features, CC BY 3.0 IGO; this issue owns 83 members. UN SALB lists a validated administrative polygon snapshot from 1996-01-13 to 2021-01-20 and names the national mapping authority, but no current official code/boundary crosswalk was acquired. The 2011 UN state report describes 16 prefectures, 71 subprefectures, 2 administrative control areas and 175 municipalities; it establishes historical role/count context, not modern completeness.
* **Chad:** the retained 2019 OCHA geoBoundaries source has 70 ADM2 features, “Departments,” CC BY 3.0 IGO. The issue has 64 direct subjects plus 17 derived ecological portions. The exact TCD ADM1 parent source in the pinned lineage is 2017 OSM/Wambacher and ODbL, separate from the administrative ADM2 source. A 2010 UN state report records 22 regions, 57 departments and 254 sub-prefectures at that time. It does not prove the 2019/now current boundaries. Wayi needs exact crosswalk work as noted above.
* **Congo (Republic):** the retained 2007 source has 46 features and is Public Domain, but current geoBoundaries metadata calls its canonical role “Unknown.” The University of Texas Libraries catalog describes the original dataset as districts and communes as of January 2007; the exact scoped member set mixes names and the source does not provide a feature-level administrative type or code. The current parent source is 2017 OSM/Wambacher, ODbL. The Atlas source-feature metadata records five topology conflicts and says shared display coverage was reconciled against Natural Earth before finer source geometry. Obtain the country’s authoritative current unit and boundary crosswalk before proposing an exact role, extent or parent change. The U.S. Embassy describes 12 departments, which provides only higher-level context.
* **Democratic Republic of the Congo:** the retained 2019 OCHA source describes second-level units as “territory, city,” 189 features, CC BY 3.0 IGO; these are distinct legal unit forms at the same general ADM2 tier, so preserve the distinction per feature rather than treating the string as one type. A non-geometric query of the UN SALB/IGC validated layer (2018-05-30 through 2024-06-13) returned 219 second-level attributes. All 20 issue subjects have one or more named candidates under the same parent name; all parents agree by name. Sixteen subjects have one named candidate; four (Kenge, Tshela, Mbanza-Ngungu, Moanda) have both territory-like and city-labeled candidates under the same parent, so the 2019 feature type/code remains unresolved. Four city candidates are explicitly named in SALB: Boma, Matadi, Bangu and Inkisi. The old OCHA source contains no per-feature unit type or code to establish whether those candidates describe the exact old polygons. SALB geometry was not requested or overlaid. Its terms limit use to non-commercial and require UN/IGC attribution; the retained crosswalk contains selected names/codes only. Neither its 219 count nor the name crosswalk proves boundary accuracy or full current completeness. The parent file is 2017 OSM/Wambacher, ODbL. The Interior Ministry says its displayed open-data traces are indicative and only official texts control.

The issue itself scopes only part of the Central African Republic (83/175), Congo (46/47) and DRC (20/189); the four area coverage records include exact counts and partial-scope flags. Neighboring packet scopes are #460 and #461 for the shared Cameroon/CAR portion and #463 for the shared Congo/DRC portion. Regional area-purpose integration belongs to #459. The exact province-parent IDs and their member counts are visible in every `assessment.json` row; no combined parent decision is made. Across all cohorts, administrative counts, source labels, geometric component counts and representative-point containment are screening evidence only. No complete city, settlement, physical-land/island, coastal or current national administrative source comparison was completed.

`geometry-audit.json` adds a repeatable Shapely 2.0.7 source/baseline comparison for every subject and source cohort. Every source feature and Atlas subject polygon checked is valid; source cohorts have 463/442/103/177 touching feature-pair screens (CAF/COD/COG/TCD) and zero positive-area overlaps within each retained full source cohort. These adjacency checks do not prove there are no gaps, correct borders, or complete legal coverage. Eleven ecological portions have multiple current Atlas components (2–8 each), while their reconstructed original ADM2×ecoregion intersections and Atlas shapes overlap at 98.9% or more on the documented planar screen; this supports a fragmented derivation, not a judgment about which disconnected ecological pieces belong at the final Atlas tier. The six-source-unit aggregate above is also a planar overlay screen. Nine administrative subjects are multipart in Atlas but single-part in the original source file; retain these as unresolved boundary/topology review signals. The affected exact IDs are in the geometry audit.

Six Central African Republic Bangui arrondissement subject geometries have less than 95% planar overlap with their corresponding original 2018 source features. Their exact IDs and reciprocal overlap ratios are in `geometry-audit.json`. A 2011 UN state report describes Bangui as a city with eight arrondissements and separately reports 175 communes; later UN reporting confirms new decentralization laws were adopted in 2020 and 2021. The retained 2018 eight-unit source therefore needs an exact current legal/code/geometry crosswalk. Do not infer that these six geometry differences are errors, or transfer any unscoped units. Affected scoped IDs: `gb:CAF:ADM3:52401652B61514878619891`, `gb:CAF:ADM3:52401652B62391094293120`, `gb:CAF:ADM3:52401652B74484085536451`, `gb:CAF:ADM3:52401652B86986631052173`, `gb:CAF:ADM3:52401652B9057863164098`, `gb:CAF:ADM3:52401652B97805646674619`.

## Authoritative reference sources

* [UN SALB Central African Republic](https://salb.un.org/en/data/caf): national authority and validated polygon validity metadata. Page response was not retained; see `reference-source-checksums.json` and its restoration URL.
* [UN CEDAW state report on the Central African Republic (2013)](https://digitallibrary.un.org/record/755696/files/A_HRC_WG.6_17_CAF_1-EN.pdf?registerDownload=1&version=1&withMetadata=0&withWatermark=0): 2011-era administrative structure. Do not treat this as a current boundary product.
* [Central African Republic Government portal](https://www.gouv.cf/index.php/article/56/la-republique-centrafricaine): describes the national 7-region/16-prefecture/72-subprefecture/175-commune structure, but its page does not date the count and conflicts with later reports of the 2020 subdivision law. [MINUSCA on the later decentralization law](https://peacekeeping.un.org/fr/node/129335) supports the existence and implementation of the 2020 reform but is not the promulgated law or boundary dataset.
* [UN CEDAW state report on Chad](https://digitallibrary.un.org/record/711369/files/CEDAW_C_TCD_1-4-EN.pdf): historical 22-region/57-department/254-sub-prefecture statement, not a current map.
* [University of Texas Libraries catalog: Republic of the Congo, districts and communes, 2007](https://geodata-prod.lib.utexas.edu/catalog/stanford-hz799nq4536): source dataset description and date.
* [U.S. Embassy, Republic of the Congo geography](https://ambacongo-us.org/about-congo/geography): states the country is divided into twelve departments; context only, not a boundary layer.
* [DRC Ministry of Interior, provinces and territories](https://interieur.gouv.cd/ministere/territoires): current institutional context; its page says the mapped open-data traces are indicative and official texts control.
* [UN SALB DRC](https://salb.un.org/en/data/cod): IGC authority and validated polygon coverage through 2024-06-13; the selected non-geometric crosswalk is in `current-crosswalks.json`.
* [UN SALB Terms of Use (2021)](https://salb.un.org/sites/default/files/wysiwyg_uploads/docs_uploads/TermsOfUseSALB2021.pdf): SALB is for non-commercial use; users must credit the United Nations and the contributor named in metadata, and must not alter data geometry/content without contributor consent. This packet retains no SALB geometry.
* [DRC Organic Law 08/016 (2008)](https://www.leganet.cd/Legislation/Droit%20Public/Administration.ter/L.08.16.17.10.2008.htm): cities/territories and downstream entities in the statutory territorial structure. The 2010 amendment should be considered for current mapping.
* [RESOLVE ArcGIS item](https://www.arcgis.com/sharing/rest/content/items/37ea320eebb647c6838c23f72abae5ef?f=json) and [2017 layer](https://services.arcgis.com/P3ePLMYs2RVChkJx/arcgis/rest/services/Resolve_Ecoregions/FeatureServer/0?f=json): item description, ecological product identity, license and five selected original features are retained and hashed.
