# South-Central Pacific interior review — bounded evidence packet

**Issue:** [#405](https://github.com/ChengshuLi/WorldAtlas/issues/405)
**Scope:** exactly 23 pinned location IDs, 23 province IDs, and 10 area slices in `scope.json`.
**Baseline:** issue scope release `geography:review:df86cbaeaf2e18f16ddf2906ef089768baac22f4428e28ed0a4724296cbb413e` v5, with hierarchy/footprint and frozen-scope hashes retained there.
**Disposition:** review evidence only. One sourced likely boundary omission is correction-needed; all other rows are insufficient evidence for complete present-day outlines. No geographic or production data changes are proposed here. This packet does not approve the region, certify all parent boundaries, or enable imports.

## Findings at a glance

- `location-assessments.csv` evaluates every member individually; `province-assessments.csv` covers every parent unit; `area-assessments.csv` covers all ten scoped area purposes and marks partial slices explicitly; `source-policy-review.csv` covers the four absent original policy profiles. The member counts are workload partitions, not geographical proof.
- The 21 Natural Earth-backed subjects now have a pinned exact 2022 source comparator and retained scoped originals: all 11 Cook Islands ADM1 features, all five French Polynesia group features, the four-island Pitcairn group feature, and eight U.S. Minor Outlying Islands features (four neighboring units retained for comparison). The full global Admin1 file is not stored; its URL, source SHA-256, commit and deterministic subset rule are in `source/provenance.json`.
- Natural Earth licensing is public domain; its 1:10m geometry is a generalized cartographic reference. The source `admin` field and feature name are useful crosswalk evidence, but they do not prove a legal local boundary or exhaustive island coverage.
- The two previous Cook identity/name/parent corrections for COK-4951 and COK-4956 are preserved from merged #502/#512. They must not be proposed again. Those predecessor materials do **not** certify the 11 Cook outlines. Atolls can be represented as broad lagoon-enclosing source boundaries while this atlas stores land islets; planar source overlap is therefore diagnostic only.
- Current French Polynesia group names have official planning/service use. Society is divided into Windward and Leeward; the service also uses Austral, Marquesas and a combined Tuamotu-Gambier circumscription. This supports coherent group meaning, not a current complete shoreline for each disconnected group.
- The USFWS distinguishes terrestrial refuge acreage from much larger submerged refuge/monument extents for Baker, Howland and Jarvis. Palmyra is a many-islet atoll with marine protected waters. These official sources support separate island identity and warn against using NWR polygons as land.
- UNESCO supports Henderson as one of four Pitcairn-group islands. The retained Natural Earth source is the four-island parent unit, not a dedicated authoritative Henderson boundary.
- The Kiribati source is OSM-derived geoBoundaries ADM1 with an empty canonical unit label. Government sources list the Line Islands as eight islands; the current source feature has five multipolygon components. Resolve administrative meaning and island coverage before claiming completeness. Issue #611's Phoenix finding remains separate.
- The baseline `location-policy.json` has no original profiles for COK, PCN, PYF or UMI, and `administrative-sources.json` has no entries for those codes. `source-policy-review.csv` examines each gap against the current scope's actual sources. Official shipping/planning/heritage/refuge descriptions support different geographic meanings, but none validates Natural Earth's island/archipelago outlines; the absent profiles remain a recorded limitation, not a license to infer local boundary rules.
- **Chile is a concrete correction candidate:** the 2020 geoBoundaries `Isla de Pascua` commune source contains a separate component near Sala y Gómez; the current atlas polygon surrounds Rapa Nui only. Chile Law 16,441 defines Easter Island and Sala y Gómez within one department/commune-subdelegation and establishes the municipality. The bounded dependent investigation is [#1052](https://github.com/ChengshuLi/WorldAtlas/issues/1052); preserve the current ID/parent until its geocoding and source-purpose checks support a separate correction.

## Geometry screening and limits

`geometry-comparison.json` is reproducibly generated by `verify.py` using the shared `worldatlas-evidence-geometry-v1` helper. It reports WGS84 ellipsoidal area intersections (`m²`) between the pinned current features and (a) exact geoBoundaries features for Isla de Pascua and Line Islands or (b) the original Natural Earth 1:10m Admin1 comparator. Source edges are integrated as straight segments in longitude/latitude. For COK-4951/4956 it uses the physical source object crosswalk documented by the merged #502/#512 predecessor. For Henderson it compares the current island only to the broader four-island Pitcairn group, and marks that as a source-tier diagnostic. `geocode-screen.json` records the atlas representative point for Isla de Pascua and WGS84 distance to a point on the detached source component, without treating that distance as territorial membership evidence.

These ratios and component counts are **not** coastline scores or completeness claims. Areas use the stated WGS84 ellipsoidal method; they do not decide whether source boundaries intentionally enclose lagoons, include cays, or use a different date. A differing polygon is a reproducible investigation signal only. The exception with legal corroboration is the geoBoundaries Sala y Gómez component: it is remote and small, but independently named and explicitly within the Chilean department/commune definition. Follow-up #1052 must inspect atlas member/point consequences before proposing a geometry change.

## Granularity and named risk screen

- **Fragmented urban/municipal enclaves:** none of the scoped units is an urban municipal cluster. Rapa Nui is a single island commune; its detached Sala y Gómez source component is material and should not be dropped just because it is remote.
- **Province-sized or oversized units:** the Polynesian archipelago groups and Line Islands are broad, disconnected, multilateral units. Their suitability depends on the atlas's published group tier; do not infer a single local municipality from `ADM1` or combine distinct sovereign parents.
- **Anonymous remainders:** none is named as an anonymous residual; source metadata does not supply an unexamined remainder exemption.
- **Disconnected territories:** expected for all archipelagos, UMI island locations and the Rapa Nui commune source. MultiPolygon/multipart source structures require explicit member/islet completeness review.
- **Repeated tiers and weak parents:** five French Polynesia polygons correspond to archipelago/planning groups while Society's two subgroups nest inside the Society archipelago; the combined Tuamotu-Gambier unit has documented government service use. These are not automatically equivalent to statutory province/ADM1 units. Cook island locations are local physical islands but Natural Earth ADM1 fallback is not proof of island council limits. Pitcairn is one nested individual island under four islands. Kiribati's canonical tier is blank.
- **Neighboring granularity and sovereign continuity:** the Cook Northern operational list includes Nassau and Palmerston beyond this 4-member slice; source records must not use this slice as a complete Northern group. Kiribati's Line chain shares physical geography with U.S. Palmyra/Jarvis but must retain distinct state parents. French Polynesia windward/leeward and five archipelago labels use official service/planning language but their spatial assignment remains an open boundary question.

## Reproduction

From the repository root, install the pinned geometry library into a temporary target and run:

```sh
python3.12 -m pip install --target /tmp/worldatlas-geo-helper -r data/regional-review/regional-review-14a242c4cb0781a7/requirements-review.txt
PYTHONPATH=/tmp/worldatlas-geo-helper:scripts:scripts/evidence python3.12 data/regional-review/regional-review-14a242c4cb0781a7/verify.py
```

The verifier checks the exact 23-member, 23-parent and 10-area scope; one-to-one feature coverage; baseline and source hashes; the four absent original policy profiles; exact source feature IDs/counts; and regenerates the comparative geometry diagnostics, controls and Rapa Nui representative-point screen. To reconstruct the full Natural Earth source for a clean external check, download the raw Admin1 file at the pinned commit URL from `source/provenance.json`, verify SHA-256 `22d0e3ad85eb3e27f17cabf8ba2d50e554fbc27a87796ff891d958185da62fb5`, then apply the recorded feature selection rule. To reconstruct the complete Chile ADM3 source, fetch the pinned LFS pointer and content URL; verify LFS oid `f3833ce1965394ae705e3793b50bdd007775b43da604251871deffed04f3bffd` and 171,783,952 byte size before extracting shapeID `31580391B33082267781919`. The local exact object is retained to avoid committing that nationwide 171.8 MB dataset.
