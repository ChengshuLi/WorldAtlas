# #927 Artigas contested territory research

A narrowly scoped, source-only research packet for the exact Artigas ADM1 subject and the IGM's separate `Rincón de Maneco` / `Isla Brasileña` contested records. Start with [findings.md](findings.md), then inspect [source-inventory.json](source-inventory.json), [reproduce.py](reproduce.py), and [reproduction-results.json](reproduction-results.json). The evidence receipt is [evidence-quality.json](evidence-quality.json).

The existing Atlas geometry, stable ID, parent and source data remain unchanged. The evidence supports recording Uruguay's map assignment and contested treatment, plus the dated treaty and bilateral context; it does not resolve Atlas administrative membership or approve a boundary.
