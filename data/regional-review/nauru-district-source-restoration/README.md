# Nauru district and island source restoration

**Issue:** [#612](https://github.com/ChengshuLi/WorldAtlas/issues/612)
**Baseline:** `7e0d5c97aeb1f0d98ac035959a2fe7a3cafe99c3` (main after #526)
**Scope:** `atlas:territory:NRU` plus its 14 district context records. This is an evidence-only packet; no hierarchy, geometry, grid, identity, application code, schema, certificate, or live data was changed.

## Finding

Nauru’s Bureau of Statistics (NBS) operates/credits the PopGIS3 Naoero district map service. Its API names a `District` layer and returns codes 01–15. Fourteen entries correspond to the census report’s stated 14 administrative districts. The extra code 15, `Location`, is a distinct census reporting/locality entry; the official 2021 census narrative calls Location a settlement and mentions Denigomodu and Aiwo. Neither source proves that Location is a fifteenth administrative district or an alias for Yaren. The crosswalk therefore keeps it separate and unresolved.

The official service has spatial data, but the retrieved district layer is a proprietary GCO5 binary packed in gzip, marked NBS copyright, with no open reuse license located. The embedded map metadata identifies `NRU_DID_2011_4326` / `nru_did_2011_4326_DR` and a 2011 district geography vintage. The official 2021 census maps appear to display later census information against this older district framework. Layer code advertises `4326` while embedded projection/calibration metadata appears to use Web Mercator; this requires source-owner confirmation before interpreting coordinates. We did not retain or redistribute these bytes. A prototype decoder generated invalid/self-intersecting shapes for many features and did not support a defensible district overlay. Accordingly, this is evidence that an official 2011 map layer exists, not a validated district-boundary restoration or exact geometry crosswalk.

The NBS 2021 Census Analytical Report (published August 2023; census day 2021-10-30) states that Nauru is one main coral island of 21.1 km² divided into 14 small districts. The 14 geoBoundaries NRU ADM1 features have a union of about 21.451447 km²; the current atlas territory is about 19.841771 km². In the prior #140 reproducible screen, their symmetric difference is 2.392553 km², 98.0272% of the current feature overlaps the district union, and 90.671422% of the district union lies inside the current feature. These area figures are not boundary verdicts: reported land area and generalized/digitized shorelines have different measurement, scale, registration, and vintage characteristics. The retained geoBoundaries dataset is secondary (boundaryYear 2005), notwithstanding its declared Public Domain license. No authoritative, licensed, validated vector boundary was recovered here.

## Sources, rights, and restoration

Canonical URLs, retrieval date, byte counts and SHA-256 values are in `source-receipts.json`. The full public-domain geoBoundaries GeoJSON and metadata are already retained unchanged in the sibling #140 packet at `data/regional-review/regional-review-4857646bb9b55df5/sources/`; that packet’s manifest records their hashes. The official census PDF and PopGIS layer are not retained: no explicit reuse permission was found for the PDF, and PopGIS reports NBS copyright with no open license located. Restore only from the canonical URLs in the receipts and verify the recorded hashes; if current URLs return unavailable or changed content, document that and ask NBS/SPC for a current authorized extract/license. Do not redistribute the proprietary layer.

The NBS announcement dated 2024-02-08 links the 2021 census tables and maps to PopGIS3. The service’s reference and initialization responses identify NBS as the source; SPC hosts the PopGIS platform. The district reference response contains a server header date in July 2026 and all 15 code/name pairs. No claim is made that a July 2026 server timestamp is the boundary publication date. The map layer embeds a 2022 build timestamp but names a 2011 source dataset; its declared layer naming, apparent projection metadata, and date need source-owner clarification.

## Reproduction and uncertainty

Run `python data/regional-review/nauru-district-source-restoration/verify_packet.py` from the repository root with Python, Shapely 2, and pyproj installed. It checks the exact 15-row crosswalk, one-to-one coverage of all 14 geoBoundaries features, source receipt hashes for the already retained source, and independently reproduces equal-area current-vs-secondary-source measurements in EPSG:6933. It does not download, decode, or assert geometry from PopGIS. The input baseline extract and geoBoundaries source are read from the sibling #140 evidence packet and are not modified.

Uncertainty remains about exact shoreline/date, PopGIS coordinate calibration and legal re-use, district polygon validity and relationship to the 2021 census table, Location’s exact spatial extent, and whether singleton framework tiers have distinct semantics. These are evidence gaps, not completion by assumption.

## Integration and bounded follow-up

This packet gives regional integration (#139) new official source leads and a 14-name/census-locality distinction. It requests coordinated follow-up with NBS/SPC (authorized native GIS export, projection/calibration, source date, license, and Location crosswalk) before any exact footprint correction. No neighboring region boundary is implicated by the available evidence. If an official vector and rights statement cannot be obtained, keep the Nauru shoreline and Location geometry unresolved and create a bounded source-access follow-up. Completing this packet does not approve the complete Equatorial Micronesia region or enable historical imports.
