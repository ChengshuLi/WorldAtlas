## Sourced findings requiring engineering follow-up

1. **Hainan scope completeness:** Hainan's official 2024 Statistical Yearbook table 1-1 lists 19 place rows for 2023 and includes Wuzhishan City. The issue contains 18 Hainan source rows and no Wuzhishan. It separately includes `Qiongshanshi`; an official local Haikou government history records Qiongshan City's conversion to Qiongshan District in 2002. The 2017 source roster is therefore not a complete present-day Hainan unit roster. Retrieve the available 2025 yearbook's 2024 table 1-1 before final current-status certification.
2. **Wenchang/Sansha parent conflict:** The source feature `gb:CHN:ADM2:17275852B41190306193582` is `Wenchangxian`; its pinned 2017 source bbox is `[110.429148605,19.282446738,111.033916258,20.133496589]`, on Hainan Island. The current Atlas parent is `Sansha`. The official Hainan yearbook lists Wenchang and Sansha separately; a central-government ministry source describes Sansha as the Xisha/Zhongsha/Nansha islands, reefs and sea area. **Propose parent/name correction to engineering**, retaining the source ID and geometry until an authoritative current boundary crosswalk is available.
3. **Obsolete or discordant Hainan names:** `Qiongshanshi` is an old Qiongshan City source feature, now requiring correspondence with current Haikou/Qiongshan District boundaries. `Dongfanglizuzizhixian` is an older source name/administrative class while current official material lists Dongfang City. `Chanzhoushi` differs from official “Danzhou”; `Shanyashi` differs from official “Sanya”. Keep source labels intact in this evidence and route sourced naming/tier crosswalks to engineering; do not rewrite core geography here.
4. **Parent assignment evidence:** The 51 framework parents reproduce the issue counts, but the 2017 geoBoundaries source has no county code or parent code. Official current directories support city/county names and broad administrative tiers, not the 198 individual source-ID-to-current-parent assignments. Mainland row-level parent claims remain unverified; particularly inspect historic county/municipal changes in Shenzhen, Zhuhai, Guangzhou/Foshan and Hainan.
5. **Source granularity and boundaries:** geoBoundaries declares County Level but describes only a 2017 reference. The HKG/MAC compact aggregates use a different source role and scale. No source in this packet proves present legal boundary quality or complete island/coastal coverage. Check current official map/administrative-boundary data and reuse terms along all adjacent Guangdong, Guangxi, Hainan, SAR, mainland-China, Vietnam and South China Sea units before any geometry integration.
