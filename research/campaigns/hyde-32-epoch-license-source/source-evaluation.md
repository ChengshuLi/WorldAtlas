# HYDE 3.2.1 access, license, and epoch review

Issue: [#65](https://github.com/ChengshuLi/WorldAtlas/issues/65)

Campaign: `hyde-32-epoch-license-source`

Evaluation date: 2026-10-03 UTC. Dataset edition inspected: DANS Data Station Archaeology version 2.0, containing the author's HYDE 3.2.1 release.

## Scope and existing evidence

This review resolves the earlier access question using the ordinary public DANS landing page and metadata API, the DOI registration record, the published article, and the release README. It does not download the multi-gigabyte population or land-use archives, inspect raster values, or prepare estimates. Eight distinct source artifacts are summarized as nine findings below; URLs, response hashes, file IDs and restoration details are recorded in [`source-manifest.json`](source-manifest.json).

The existing [source inventory](../../../data/source-inventory.json) and [historical coverage review](../../../docs/HISTORICAL_COVERAGE_RESEARCH.md) identify the dataset as a candidate but leave its data-specific rights and actual file availability unverified because an earlier request encountered an anti-bot page. On 2026-10-03, the DANS page and standard public API returned HTTP 200. The current record reports five public, unrestricted files. The prior access blocker is therefore resolved for metadata and the release README; no claim is made that the 5.1 GB archive has been downloaded or raster-validated.

## Findings

1. **Pinned repository edition.** DOI `10.17026/DANS-25G-GEZ3` resolves to “Anthropogenic land-use estimates for the Holocene; HYDE 3.2”, published 2017-09-29. The current DANS repository edition is version 2.0, released 2025-06-02. Its files identify the payload as HYDE 3.2.1. This record version and payload release are distinct version labels and dates.
2. **Public access and file listing.** The DANS page, API, and DataCite record are publicly readable without credentials. DANS marks all five listed files public/unrestricted: `easy-migration.zip`, `HYDE3_2_1-anthromes.zip`, `HYDE3_2_1-baseline.zip`, `HYDE3_2_1-general_supplementary.zip`, and `readme_release_HYDE3.2.1.txt`. The baseline ZIP alone is listed as 5,339,653,974 bytes; the page labels the combined download 5.1 GB and the README says extraction totals 77.8 GB. Only the 8,826-byte README was downloaded. No grid ZIP or raster was downloaded.
3. **Dataset-specific license and a conflicting notice.** The current DANS version 2.0 record expressly lists `CC0-1.0`; its public page and DataCite DOI metadata repeat CC0/open-access rights. This is dataset-level evidence, separate from the article's license. However, the author-provided release README, included in the current record, states: “The Creative Commons License (CC BY 3.0) applies to all of the HYDE data.” These repository and included-file declarations conflict. Both permit reuse; until DANS or the author reconciles the notices, use CC BY 3.0 attribution as the conservative practice, cite the dataset DOI and article, and identify changes. No source bytes or data are redistributed by this review.
4. **Product period and model time steps.** The article and README say HYDE 3.2.1 covers 10,000 BCE–2015 CE. The issue's evaluated window remains 3000 BCE–2015 CE; the broader product start is recorded only as dataset context. The README describes 1,000-year steps in the BCE period, then 100-year steps through 1700 CE, 10-year steps through 2000, and annual steps from 2000–2015. These are model-output time steps, not independent observations or a promise of uniform evidence quality. The examined README does not define whether each filename year denotes a start, midpoint, or end of an averaging interval, nor settle a BCE/CE year-zero convention; do not silently invent one.
5. **Grid header template and precision.** The README documents Arc/Info ASCII grids with 4,320 columns × 2,160 rows, lower-left corner (−180°, −90°), 0.0833333° cell size (5 arc-minutes, about 85 km² at the equator), and NoData −9999. This is the published header template, not a sample raster header. No epoch raster headers were inspected (0 of the permitted maximum 5). Cell area varies with latitude; do not treat 85 km² as the area of every cell.
6. **Population units and modeled basis.** README variables distinguish `popc_<year>` total population counts in inhabitants per grid cell, `popd_<year>` density in inhabitants/km², `rurc_<year>` rural population counts, and `urb_<year>` urban population counts. `uopp_<year>` is built-up area in km² per cell, not a population count. The article says 1950–2015 country totals draw principally on the UN World Population Prospects 2008 revision and pre-1950 estimates draw on historical demographic sources, supplemented by subnational series. It allocates those totals spatially using model weighting maps, including contemporary LandScan (2014) population patterns for 2012 as present-day weights. These are reconstructed/modelled estimates, not local census enumerations; urban/rural are population categories, not settlement observations. A numeric zero is not a separate source statement that a place was uninhabited; NoData is −9999.
7. **Administrative and land-use denominators.** The article says it holds current administrative units constant over time for simplicity and adjusts some older, larger historical sources to those units. README country totals are model summaries, not historical atlas-territory counts. Any future use would need a separate, approved footprint allocation and denominator review; this campaign makes none. Cropland, rice, grazing, pasture, and rangeland grids are estimated land-use areas in km² per cell, not observed vegetation classes. The article notes an Australia-specific “non-used areas” mask for agricultural allocation from an NLWRA 2001 map; that model exclusion is not evidence of no population or no settlement.
8. **Uncertainty and product variants.** The release lists Baseline, Lower, and Upper scenarios. The article discusses source variation and lower/upper uncertainty ranges, but the examined metadata does not define the variants as calibrated probabilities or confidence levels. Preserve the variant labels and estimates; do not collapse them to a precise observation or infer certainty. Anthromes are a derived land-system reclassification, not direct settlement counts or fixed WorldAtlas vegetation classes.
9. **Reuse and review boundary.** The article itself is CC BY 3.0; that article license alone would not establish data rights. DANS now supplies usable dataset-specific CC0 metadata, while the included README retains a CC BY 3.0 statement. The matching attribution practice covers the stricter notice pending clarification. Data are accessible for future lawful work, but this source-only result does not authorize import, establish historical location subjects, validate any raster values, map current codes to historical boundaries, or create yearly Atlas records.

## Decision and remaining scope

The earlier access blocker is resolved for the exact DANS version 2.0 / HYDE 3.2.1 record: metadata and its small README are accessible, and the record declares CC0-1.0 for the dataset. The author README's included CC BY 3.0 notice is retained as a real terms discrepancy; practical reuse can proceed with attribution and citation while that wording is clarified. The large archives remain uninspected. No global downloads or estimates were made, and no sample epoch headers were retrieved.

The product contains modeled population and land-use estimates at uneven published time steps through 2015. It distinguishes grid-cell counts from densities, but source code fields do not themselves describe an Atlas location's territory. The issue's requested epochs are documented; their exact per-file date-anchor semantics remain unspecified in the inspected README. A later bounded child would be needed before any selected raster content could be considered, and would require the applicable complete published regional approval certificate, permitted subjects, and matching release pins before import.
