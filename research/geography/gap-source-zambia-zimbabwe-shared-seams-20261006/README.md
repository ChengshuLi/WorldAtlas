It performs no longitude wrapping, coordinate transformation, snapping, buffering, simplification, `MakeValid`, or nearest fill. Exact producer bytes match between the two final runs. Positive and negative controls exercise a real source intersection and a disjoint source feature against the actual input products.

The local country-union extent is the bounding box of the ten issue components expanded by 0.05 degrees in each direction. All whole-country source and Atlas ADM2 features are indexed; all features with bounding boxes in that local extent contribute to the local unions. The comparison is not a country-wide certification. WGS84 component and polygonal overlay areas use straight source-edge integration; planar degrees-squared and degrees are retained only as operation diagnostics. No feature overlap adjudicates ownership or proves an executed processing stage.
