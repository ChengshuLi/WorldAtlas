# Northern India–Pakistan seam source packet

This packet compares the two retained pre-water physical-gap fragments against the immutable geoBoundaries source releases for Indian ADM3 simplified (2018), Indian ADM2 (2021), and Pakistani ADM2 (2019), plus the current Atlas features for the issue's exact 16 subjects. It records source vintage differences rather than treating these layers as one simultaneous survey.

The Indian GeoJSON files are larger than the evidence policy's 32 MiB per-file ceiling. Their complete original bytes are retained as ordered, non-overlapping raw byte parts. These parts are not feature extracts or rewritten GeoJSON. Concatenate each layer's parts in offset order to reconstruct the exact upstream object, then verify its whole-file SHA-256 against both the source manifest and upstream Git LFS object ID. The Pakistan source is retained whole because it is below the ceiling. No source geometry is snapped, buffered, repaired, filtered or reassigned.

`source-custody.json` records pinned upstream commit IDs, file paths, GitHub blob IDs, Git LFS OIDs, retrieval URLs, whole-file sizes and hashes, exact part offsets and hashes, the upstream per-layer metadata and reported licensing. `source-crosswalk.json` records all 16 Atlas-to-native IDs and inspected source names. `reproduce.py` restores the originals, validates the full byte hashes, checks exact source membership, and compares source and current geometries using the repository's pinned WGS84 evidence geometry helper. Outputs retain tiny positive overlaps, collapsed or non-polygon remnants, errors and explicit unknowns.

The 2018, 2021 and 2019 boundary-year labels are separate dataset vintages. The shared metadata records source-data update date 2023-01-19 and build date 2023-12-12; those dates describe source processing, not a common observation date. Water and disputed-affiliation status remain unverified.

The Indian source metadata reports `admUnitCount=6836` for the ADM3 layer and `736` for ADM2; the retained complete GeoJSON objects contain 6,822 and 735 native features, respectively. Those catalog-count differences are retained as unresolved metadata discrepancies. They do not change the exact 16-member crosswalk. The source date labels remain 2018 (IND ADM3 simplified), 2021 (IND ADM2), and 2019 (PAK ADM2); no common observation date is inferred. The crosswalk includes each original member name, the current Atlas source-member lineage/hash, and full original/current feature digests.

For independently dated physical context, the packet records ESA WorldCover 2021 v200 (released 2022-10-28, CC BY 4.0; DOI 10.5281/zenodo.7254221) as an official comparator. It was not sampled: no WorldCover pixel supports this packet's findings. The physical fragments remain unverified for land versus water, and no disputed affiliation is assigned. The inherited Natural Earth 10m water reference covers major lakes/reservoirs only and is modern rather than year-specific; absence of a recorded coarse-lake intersection cannot establish dry land.

## Findings and bounded limits

`assessment.json` records the supported crosswalk and the baseline-vintage measurements, then separates the unresolved cause of the geometric differences from physical-surface and affiliation questions. The final committed-code runs are byte-identical and bind to code commit `4e35869912bc5a7e0b222a3751219347443a34dc`; their Atlas data inputs are the immutable `c603befd3aaf4da90d59b12378e1e0739331efba` baseline. The 18 Atlas contacts and zero original-source contacts therefore describe that baseline comparison, not the newer main revision.

Across the two full fragments, the retained geometry ledger measures 2,362,541,936.078026 m² combined. It also preserves the source/current per-subject overlays, all polygon and non-polygon components, zero contacts, tiny positive intersections, and explicit measurement failures. The controls cover geometry collections with mixed atoms, disconnected polygons, holes, true zero-area line/point contacts, a tiny positive polygon, invalid geometry, exact source crosswalk behavior, and full-byte reproducibility. See `runs/run-1.json`, `geometry-controls.json`, `source-controls.json`, and `two-run-reproducibility.json`.

The source comparison does not distinguish the causal contribution of source simplification, the three different administrative tiers and boundary years, and Atlas reconciliation. ESA WorldCover 2021 v200 remains an unqueried comparator; the coarse Natural Earth lakes reference cannot resolve land versus water. Both fragments' surface and affiliation remain unknown, and no geography is approved by this packet.
