# Research terrain screening

This generic research tool samples a line and terrain cross-sections from locally supplied DSM and mask rasters. It does not change a boundary, establish downstream flow, or certify a watershed. The user supplies the geographic data; none is stored in this directory. Only mask-0 pixels with non-NoData elevation enter summaries. Confirm mask semantics against the actual source and use a suitable local projected CRS to preserve the source-line geometry; all geographic lengths and offsets use WGS84 geodesics.

Requirements: Python 3 with GDAL/OSR, NumPy and pyproj. Run tests with `/usr/bin/python3 -m unittest discover -s scripts/caucasus-audit`.

Input `--samples` is GeoJSON Point features with `section`, `source_edge_index` (zero-based index into line coordinates), and `distance_along_section_m`; input `--line` is a GeoJSON LineString geometry. Repeat `--tile` using `NddEddd:/path/to/DSM.tiff:/path/to/MSK.tiff`. Specify `--section`, `--start-vertex`, `--end-vertex`, `--epsg` (the same CRS used for sampling), and `--output` in a separate local research directory. Output contains input-derived geographic coordinates and should be handled as research data, not committed to the source repository.

The nearest-neighbor, 1-arcsecond DSM samples are indicators only. The source can contain vegetation, buildings, clouds, ancillary data and negative-elevation conversion artifacts. Check source quality, compare resolutions, consider watershed routing and uncertainty, and obtain review before accepting any change.

`sample_line.py` can produce the input points from an externally supplied LineString and user-provided section vertex bounds; use `--start-vertex`, `--end-vertex` (inclusive), `--section`, `--spacing-m`, `--epsg`, and `--output`. The endpoint is included only when its WGS84-measured path position falls on the sampling interval. Projected-linear source geometry is preserved; length is approximated as the sum of WGS84 inverse-geodesic chords no longer than 100.01 m, with sample position refined to 10 micrometres within its chord. This chord sum is a numerical path-length approximation, not an error-bounded exact length. Earlier projected-distance sample files are rejected and must be regenerated. Samples pin the canonical full source-line geometry and the selected section bounds; a change to either requires regenerating them. A sample exactly at a shared vertex uses the preceding source edge for its tangent. Its output is geographic research data and should not be committed.

For exploratory analysis, `ridge_candidates.py` takes those input samples, the line, paired source tiles, section and distance range. It identifies prominent interior peaks across a full valid-mask window using SciPy. These are profile features only: connecting peaks does not establish a continuous crest or a watershed. Output is private research data, not repository content. Optional profile testing requires SciPy.

For stronger source independence when original JAXA archives are available, provide each tile as `NddEddd:DSM:MSK:STK` and pass `--require-stack` to terrain_screen.py or ridge_candidates.py. This requires both MSK 0 and STK > 0 before any DSM height is read. JAXA states STK 0 means no PRISM data; MSK 0 alone is not always sufficient. Runs without this option are mask-screened only and must not be described as stack-qualified.

`trace_downhill.py` follows local eight-neighbor, steepest-descending paths from profile points, using WGS84 geodesic distances between raster-cell centers for slope ranking. Equal-height flat exits are ranked by the fewest grid steps first and geodesic slope second. It requires original 1-arcsecond WGS 84 JAXA DSM/MSK/STK tiles, valid MSK 0 and STK > 0, and stops before crossing unknown-mask pixels or tile edges. Provide a `ridge_candidates.py` output via `--profiles`, the selected GeoJSON LineString via `--line`, repeat `--tile NddEddd:DSM:MSK:STK`, repeat the same `--section`, `--start-vertex` and `--end-vertex`, and supply a private `--output`. By default strict descent stops at equal elevations. `--flat-limit 100` permits routing over at most 100 connected equal-height cells to their nearest downhill exit (steepest slope breaks ties); compare both modes. This only explores local surface-model descent: pits, flats, vegetation, buildings, grid resolution and masked areas can stop or distort paths. Merging paths or crossing a line is evidence for further review, not proof of a real stream, named outlet or watershed. No depression filling or forced outlet is performed. Output is geographic research data and must not be committed.

For within-source sensitivity only, `--median-window 3` or `5` applies a pixel median before tracing. All pixels in each filter neighborhood must pass the quality screen; SciPy is required. Smoothing can alter drainage and does not add an independent source. The default 1 leaves elevations unchanged.

Use `--crop-radius-pixels 250` to bound reads to a 501×501-pixel square around each profile center. Traces stop when they touch the crop boundary; a larger crop can change the result and should be considered in sensitivity checks.
