# Fresh WorldAtlas rerun: upstream checkpoint

The 2026-11-07 rerun rebuilt the native physical land/water grid from the selected OSM land polygons and all 32 Overture 2026-10-21.0 water shards. The OSM local shapefile members were independently matched to a fresh R2 readback of the cataloged archive. Every Overture shard was downloaded from R2, checked against its pinned size and SHA-256, and rasterized. All 32 resulting shard TIFFs matched the prior candidate SHA-256 values.

The original run used PR4 physical-stage files from c5e116f6 and the exact recorded local staging harness. After a transient R2 fetch failure, 18 finished water checkpoints and the finished land mask were verified and reused in a fresh output directory with the tested resume wrapper. The wrapper reports the land producer code identity as an operator assertion: the original land report did not independently record that code hash.
