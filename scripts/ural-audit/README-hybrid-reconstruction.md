# Ural main-stream hybrid reconstruction (research)

This tool builds the OSM relation 214415 version 122 `main_stream` node chain from a hash-pinned captured OSM XML file, and orients it using the reviewed starting vertex in the selected Ural boundary. It retains the selected northern prefix and its joining edge. This is a partial, hybrid reconstruction: those retained coordinates are not derived here from raw terrain or watershed sources. No geometry is selected or written to Neon by this tool.

The OSM route includes the Ural–Caspian canal. The relation's mapped mouth-role discrepancy and the principal headwater selection remain unresolved. A match to stored selected coordinates verifies reproducibility of this route against that line; it does not establish that the source defines the geographically correct boundary. Original V7 construction or matching V7 cells is not a requirement for the current source-based workflow.

The selected snapshot must contain the matching versioned source link and R2 asset SHA-256 and size. The program verifies those against the actual OSM bytes, requires the selected revision/CRS/hash method, checks a separately hash-pinned point-in-time Neon selection attestation, verifies a single connected unbranched chain, and reports the endpoint IDs and join coordinates. Source byte hashes, attestation, implementation and selected geometry are recorded; the raw OSM capture remains in R2 and selected structured geometry remains in Neon.

The source chain has 142 ways and 41,669 edges. The hybrid geometry equals selected geometry SHA-256 `5a6526344cacbc1a23be174f589cec9710a0f317360ec5c8737ba6956c3f7fe2`. This says nothing about the correctness of the retained 4,969-point prefix, the spring join, closure, or land cells.

Run with `python3 ural-reconstruct-hybrid.py --help`. Provide original source, snapshot, and current selection-attestation paths and their independently verified SHA-256 values; use `--river-start 4969` only for this exact reviewed selection. `--geometry-output` creates a local research artifact, not a selected database record. Recheck selection before any later integration. Run `python3 test_ural_reconstruct_hybrid.py` for synthetic graph and source-link tests.
