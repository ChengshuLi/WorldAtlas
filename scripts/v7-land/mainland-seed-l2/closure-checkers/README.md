# Physical closure checkers

These research validators check selected route geometry against a pinned physical grid. Their proofs do not establish geographic authority, historical equivalence, or selection. The terminal checker permits only the explicitly reported endpoint-cell contacts.

Run `/usr/bin/python3 -m unittest -q test_validate_water_closure_v2 test_terminal_closure` in this directory. The stage-2 seed producer remains diagnostic until its upstream Neon export, witness resolution, and component/physical coverage are independently authenticated.
