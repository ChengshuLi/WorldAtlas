# Third-party scan as supporting evidence

This research-only change permits an explicitly labeled `third_party_mirror_scan` as a geographic-membership citation. It does not make the mirror a geometry, source-point, boundary, or other construction selector, and does not alter any construction-source policy. The existing `provider_original` path and its output remain unchanged except that all three independently supplied byte-size pins must be exact integers.

A mirror citation must be raw, have no source-lineage dependencies, match the source, catalog and local size, digest and R2 pins, and carry nonempty scope, verification claim and limitations. Its report identifies the third-party representation and retains the catalog provenance. The local file bytes are hashed; the runtime does not verify the cited words, original-provider identity, catalog provenance, redistribution rights, or the actual remote object. The caller must authenticate the snapshot, expected catalog pins and R2 readback separately. A license URI is a catalog reference, not a rights determination. Human review remains responsible for the source interpretation and relevant limitations.

Apply only to a verified research mixed runtime whose `entry_evidence.py` base Git blob is `7cda0119959b87415448fe434c3533d878644b7b` and `test_entry_evidence.py` base blob is `cc6b5bbb22822b9152242979b63d3e34a3308ab8`. Run `test_entry_evidence` and `test_mirror_mixed_driver` in that assembled runtime, and rerun its full suite with GDAL. The separate mixed-driver fixture exercises report propagation and does not change the driver or any blocked overlays. No geographic decision, map, raw scan or structured source data is included.
