# Reef-envelope research overlay

This code-only overlay adds a source-specific relation-envelope extractor and all-center containment policy to the reviewed line-side and source-negative mixed runtime. An outer envelope is not a literal reef footprint; enclosed holes are not automatically land. The selector depends on separately supplied and reviewed source evidence and does not contain geographic decisions or source data.

The integration was tested against the extent-corrected line-side runtime, with the full 830-test suite and independent review. The overlay is not an accepted geographic publication.
