# Named List 1 point and source containment research overlay

This code-only overlay adds a source-pinned GeoNames point method tied to a selected named List 1 entry, and a generic audit of current component centers against a pinned land-polygon archive. It preserves the existing airport-witness, island-relation, and archive selector methods. Apply its changed files over the separately preserved island-relation and airport-aware runtime, retaining its sibling dependencies. Tests use synthetic inputs. Geographic decisions, raw sources, and diagnostic outputs are maintained separately and are not included here.

The named entry and point identify a current whole component; they do not by themselves prove every component cell or nearby islets. Source identity and containment require independent review. This research overlay is not a published geography partition.
