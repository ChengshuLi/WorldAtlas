# Historical territorial-envelope research runtime

This code-only preservation records the exact integrated source files used by the draft153 research build, along with adapted synthetic tests. The territorial method requires a selected geographic-group feature and a named administrative relation; it selects whole physical components only when all their centers are contained by both sources. This is a reviewed research convention, not an administrative-sovereignty rule or a production map release. Source identities, versions, bytes, geometry, protected components and decision conflicts require separate pinned checks for every build.

The files are an isolated historical overlay, not a replacement of the PR4 base, the separate all-center archive overlay, or the later mirror-evidence validator. `entry_evidence.py` is included solely to reproduce the historical runtime bytes; it predates third-party mirror support. To use the later mirror validator, assemble and test a new explicitly pinned runtime rather than overwriting the historical snapshot or assuming identity. The reef-envelope extractor is preserved separately. Other dependencies must be assembled from their reviewed pinned sources; this directory is not a standalone deployable runtime. No raw sources, geographic selections, production configuration or map data are included; the tests use synthetic fixtures; two test files replace real-world names and relation IDs with fictional values.
