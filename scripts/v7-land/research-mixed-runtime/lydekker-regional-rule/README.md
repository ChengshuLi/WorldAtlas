# Regional Lydekker whole-component rule (research)

This is research code, not a map build or a selected geography release. `component_scan.scan` reads pinned physical-component streams in two passes, counts the whole global component for each root touching the region and computes line-side counts. `replay_adapter.resolve_with_mixed_replay` invokes the existing mixed-claims combiner, preserving source-resolved pending reviews and selected source-backed individual and group assignments before proposing a side for each remaining whole component. `geonames_anchors.discover` can resolve all island points from a pinned country archive to physical components; source identity establishes an island witness, while the configured physical-size cutoff is an operational convention. `satellite_geodesic.apply_satellites` can then associate eligible unclaimed components with their nearest source-backed main-island anchor, using the existing exact WGS84 component-run geodesic. It reports conflicting nearest targets for review and records unanchored neighbors separately; lack of a name alone does not cancel an approved line-side proposal. No individual cell is patched.

The existing production/research driver does not invoke these modules. A real execution still requires an authenticated source replay, complete source anchors and competing-land search, explicitly selected operational parameters and decision selection. The nearest-island association is a geographic convention, not proof of group membership. Established selected group claims take precedence. The code does not turn a source-based rule into a change to the current map.

The caller must read the revised line from Neon project `wild-cherry-46472487`, branch `br-shy-mountain-arsff6zb`, table `atlas.geographic_line_observations`. The workflow pins `lydekker-anu-figure81-regional-boo-east-v2` and canonical compact sorted GeoJSON SHA-256 `87514ff08498fa2e2a27bfe2f0a1026511b3c5f01acfbaecbf1f753392c33655`; `verified_line` checks the exact geometry, source ID/version, research status and PDF provenance. ## Execution contract

- Authenticate the line, catalog and revision, physical component generation, source-backed main-island identities, and all selected affiliation/group evidence. Root IDs are temporary identifiers for the component generation, not persistent geography decisions. The scanner checks stream shape, order and hashes but does not establish that the components match the physical mask.
- Resolve documented pending group conflicts to physical roots from authenticated source witnesses and pass them as `pending_claims`. Those components remain unresolved even if a line-side or historical selected target exists; neither the line nor the satellite pass may override them. Then replay all selected source-backed group and individual claims. They win over the line, and apply to the whole component, including portions beyond an endpoint. Conflicting selected codes and claims that touch protected mainland witnesses fail the replay. Existing nonregional selected codes are preserved.
- Unclaimed, whole components entirely inside the selected regional window and on one side of the supported line receive a line-side proposal. Partly out-of-window, on-line, or split components are flagged; no endpoint is extrapolated. A longitude difference up to 1e-10 degrees from the interpolated line is considered contact solely to absorb floating-point rounding. This is not a geographic uncertainty margin.
- For the satellite pass, resolve source-backed named main-island witnesses to complete physical roots, authenticate the existing stage-2 `run_pair` code and its dependencies, and include every larger competing component within the search distance, even if unnamed. The composed workflow scans a conservative geographic buffer and reads complete runs for every buffered component; callers supplying a custom anchor set must authenticate it. Each anchor must already have an unambiguous selected or line-side target. Selected affiliations are never overwritten and inferred satellites are not reused as anchors. Incomplete candidate frames can select the wrong parent and are not acceptable.
- Supply a maximum satellite size and WGS84 center-to-center gap as explicit, reviewed operational parameters. An earlier regional preview used at most 20 cells and 5 km, but that preview described both as conservative assumptions, not source-defined geographic boundaries, and used planar distances. They are not automatically adopted by this code. The project stage-2 tie tolerance is 1e-5 metres and its baseline uses a lowest-code tie break. This proposed satellite rule instead reviews conflicting known nearest targets. An unanchored nearest component alone does not cancel a line-side proposal; it is recorded for source-coverage diagnostics. Beyond the endpoints, an unanchored neighbor does not supply a target. The implementation prunes component-run comparisons using a conservative spherical lower bound with the project’s 1 km numerical cushion before evaluating exact WGS84 run pairs; the bound is not a formal proof against every floating-point error.
- Center-side tests do not establish that a continuous line misses polygon interiors; preserve and verify the separately pinned polygon-intersection proof. Integrate and independently validate the source replay, complete scan, satellite search and decision selection before any map build. No selected exception is created by these modules.

Selected Asia assignments for endpoint-spanning Yamdena and Wetar must remain whole. Constant-longitude southward extrapolation would misclassify an Australian component; Timor, Sumbawa, Flores and Sumba already have selected Asia assignments beyond the southern endpoint. Boo Besar has a source point on a historical Oceania component west of the line, and published material groups Boo with Kofiau/Raja Ampat. Boo Besar has 73 physical cells, so the earlier 20-cell / 5 km preview assumptions do not themselves resolve this group. The user subsequently directed that the boundary be moved smoothly so Boo lies on the Oceania side. When the requested window contains the GeoNames Boo Besar witness, the workflow resolves it against the pinned physical stream and requires the entire component to lie on the revised line’s Oceania side. It fails rather than allowing another pass to produce a conflicting result. No Boo-specific per-cell exception is used. The revised line has been registered and its geometry and source linkage independently verified in Neon.

A read-only comparison with the pinned prior regional audit matched all 6,486 touched roots and 15,263,342 in-window land centers, including full component counts and side partitions. Using the superseded line and before the Boo revision, the historical draft-170 reconstruction produced 2,675 selected roots and 2,488 unclaimed single-side roots; 1,315 roots outside the line's latitude and eight partial-window roots are reviewed. Those historical claims include conservative supersets. This is not a fresh complete replay or satellite impact result. A historical-input read-only source check scanned 6,148 GeoNames Indonesian ISL records, matched 1,744 buffered roots and found 607 size-eligible anchors at the provisional 20-cell threshold; 2,778 points fell in water at this grid resolution. Named-point matches therefore do not constitute complete anchor coverage. The combined read-only workflow has synthetic integration tests with the real mixed-claims and WGS84 run-pair dependencies, including automatic source extraction and an outside-window anchor; no actual map was rebuilt.
