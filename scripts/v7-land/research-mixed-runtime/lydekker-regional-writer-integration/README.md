# Regional writer integration

The mixed writer can invoke the selected regional rule with fresh selected-source resolver reports. The hook pins the decision snapshot, policy, source files, line, current component streams, pending claims, and runtime code. Pending and protected roots are held before regional proposals; the writer retains their baseline codes. Regional statistics are reported separately.

The selected policy is research-only. A complete pending inventory, source-backed identity review, authenticated input lineage, and a fresh full-source run are required before treating a result as current geography. An incomplete inventory is permitted only as an explicitly labelled profiling stand-in. Previous archived diagnostics do not establish a fresh replay.

Run the focused tests with the active writer overlay path supplied in `OVERLAY_PATH`. Recheck every pin before and after a real run. The current independent source, line and satellite interpretations remain subject to geographic review.
