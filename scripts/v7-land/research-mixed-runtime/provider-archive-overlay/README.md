# Provider archive geometry support

This reviewed research overlay adds bounded extraction of a selected geometry from an authenticated provider archive. It preserves the GeoNames point method, closed-way support, and no-host-floor runtime. The included tests use synthetic inputs. The implementation has passed its test suite and has not yet been used in a completed selected global map build.

To reproduce the runtime layout, copy the previously preserved mixed-runtime and point/validator directories to the sibling directory names expected by the driver, then overlay these files and verify the complete code and source pins before use. No source datasets, geographic decisions, credentials, or result grids are included.
