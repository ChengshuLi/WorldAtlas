# OSM map-export support overlay

These policy and loader files were used by the draft-27 research build. They support a bounded provider-original OpenStreetMap export while verifying source identity, bounds, custody and selected relation geometry. The included tests use synthetic geography. Overlay them into the separately preserved no-host-floor mixed runtime and run the synthetic tests with its existing dependencies. This code does not contain source geographic records, decisions, credentials or output grids.
