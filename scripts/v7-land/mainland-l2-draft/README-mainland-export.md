# Mainland L2 draft schema and export

This is a **work-in-progress research interface**, not a production migration, complete stage-2 policy, or map release. `neon-mainland-l2-schema.sql` contains schema only: revision-bound stored LineString boundaries, foreign-key links to raw source assets, an immutable metric definition and revision-bound metric selections. It embeds no source geometry, raw data, credentials or selected decision records. Its existing `atlas.guard_decision_row()` and `atlas.reject_source_change()` dependencies come from the earlier source/decision migrations. Apply migrations only to an authorized isolated draft branch after review.

`query-real-mainland-draft.sql` is a read-only query for the current schema. It exports selected boundary geometries and their FK-derived `provenance.source_refs`, raw source catalog/lineage, and selected metrics with explicit `decision_revision`. It preserves the existing `worldatlas-geography-decision-draft-evidence-v1` schema and uses `%(revision)s` as a bound parameter. The canonical snapshot exporter converts decimal numerics to normalized strings. Boundary `geometry_hash_method = binary64-sorted-compact-geojson-v1` is separate: parse each coordinate to IEEE-754 binary64, serialize the GeoJSON LineString as sorted compact JSON in UTF-8 without a newline, and SHA-256 those bytes. Do not hash the string-valued snapshot geometry directly.

**Critical limitations:** `land_baseline_policy` is deliberately null and `seed_regions`, `mainland_component_rules`, `mainland_witnesses`, `mainland_witness_groups` and `mainland_group_relations` are deliberately empty placeholders because their actual database schema/selections are not yet integrated into this query. They are not evidence that a complete policy has no such inputs. Consumers must fail closed and must not run a stage-2 build until a later query reads actual selected records and validates all revision, source, route, witness, region, policy and generation links. This draft query also does not export Panama or selected closure routes. Updating schema without updating this query would leave it stale.

## Verification

On a disposable, authorized Neon branch, validate this schema with transactional rollback and source/decision FKs; never run the destructive or incomplete tests against production. Run the existing draft-export unit tests and adapter tests. For a private, authenticated read-only export, independently verify both boundary coordinate counts and geometry hashes against the selected L2 source file, source-reference joins and raw R2 object checksum, and check that the WGS84 metric selection carries the same draft revision. A geometry hash verifies bytes/numeric coordinates, not historic V2/V7 raster equivalence, geographic authority, complete source lineage or closure correctness. Do not commit or publish private snapshot files, raw sources or selected geometry data with this code.
