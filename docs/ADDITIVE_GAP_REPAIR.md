# Additive gap repairs

An effective footprint is the set containing the complete retained base polygon
and each complete admitted addition. It is explicitly **not GeoJSON** and must
not be passed off as a valid dissolved Polygon or MultiPolygon. This preserves
original coordinates even when a floating union changes its boundary predicates,
or a literal shared-edge MultiPolygon would be invalid.

The feature retains its original `geometry`, identity, parent and metadata. The
optional `additiveFootprint` binds the selected baseline release, full base
geometry, rule and ledger digests. Each addition binds its stable component ID,
whole geometry and source receipt. Additions have deterministic component order.
The browser reader checks this complete representation; it does not grant source
fitness, geographic approval or ownership transfer.

`effectivePrimitiveGeometries` returns all primitives. The explicit native adapter combines
all polygons into **one** owner entry and uses the unchanged exact native operator.
The historical native adapter, compact context, check-prepared code and scientific
operators remain literal for the existing v8 consumer-image pins.
`pointInFeature` uses set membership. The source digest includes the explicit
addition domain; unchanged legacy features retain exactly the old digest bytes.
A changed ledger invalidates native
context reuse even when the base geometry is the very same JavaScript object.
The canvas requires a supplied native grid for composite features; its viewport
bounds include the additions and it never sends a projected composite for ownership.

## Complete candidate inventory

`scripts/additive-gap-repair.mjs` provides a bounded whole-shard inventory entry.
Its committed request binds the executing code bodies, actual installed import
bodies, original complete report, original containing shard and exact selected
IDs/ordered feature-hash roster. The report preserves the independent full parent
denominator. The stage authenticates complete encoded and decoded input bodies,
charges the whole installed Node executable separately from ordinary capped
files, and reserves output before source decoding. Existing destinations,
dangling links and symlink parents fail before acquisition. Publication is last.

Every source record produces exactly one disposition row. Its alias includes the
original containing body descriptor, ordinal and hash of the **actual complete
original JSONL record bytes**, not a reserialized geometric substitute. The full
original source remains necessary for the inverse. Parent joins reject missing,
duplicate, foreign or reordered IDs and check complete disposition totals.

The current source-classification stage deliberately does not convert provisional
land into repair permission. Source-relative inland-water rows are retained as
rejected for reassignment; all other categories await complete source/target
eligibility. Original physical authority, unknown status and limitations stay in
all rows. Thus the existing complete 95,173-record classification is immediately
processable without another global geographic audit.

The repair stage and selected additive release still require the independently
reviewed common source rule, whole installed baseline and full neighbor/context
proof. Native cell assignment, zero-cell cases, batch conflicts and reversible
sparse ownership overlays must be recorded separately from geometric eligibility.
Those stages remain unfinished in this implementation checkpoint. No existing
release, map, source polygon or historical affiliation is changed by this code.
