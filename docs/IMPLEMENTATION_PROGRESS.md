## Installed foundation

The active hierarchy is **49,589 locations → 5,133 provinces → 471 areas → 66 regions → 29 subcontinents → six continents**. Antarctica is excluded. EU5 counts remain scale references rather than quotas. `data/publication-geography-receipt.json` records the actual installation and hashes; staged proposals alone do not establish what is active.

Each active location is a territory with one adjacent-tier parent chain. The shared resolver returns one value or an explicit unknown per location, attribute and selected date. Names, attributes and membership use stable identities, supported half-open intervals and no year zero. Map fills, inspector values and legends follow whole-location records. Historical political source polygons supply ownership evidence rather than independently painting part of a location.

Twenty-five source-identity unions, two seam corrections and the licensed full Vatican territory produced 27 changed footprints and 25 retired IDs. Macro membership corrections retain those installed footprints. Every changed predecessor and its evidence context is archived; geographic changes do not silently transfer historical claims. Durable installation/source receipts are in `data/geographic-repair-evidence`, `data/macro-boundary-migration.json.gz` and `data/publication-geography-receipt.json`.

## Exhaustive audit versus semantic completion

`data/global-semantic-closure.json.gz` reports exhaustive audit and structural completeness, with **semantic completeness false**: all 49,589 location reviews and all 5,705 parent-group reviews remain open. The audit proceeds continent → subcontinent → region → area → province → location. A supported parent boundary does not approve unresolved children. All six `data/geographic-decisions` files retain original inspected-source decisions, while `data/world-review.json` inventories current membership and explicit omissions/source exceptions.

Namibia's entire defective 2007 profile is visible through `data/namibia-source-quality-annotations.json`: all **111 current IDs and 24 parent groups** are crosswalked. The licensed candidate has 107 former-framework territories and 14 regional clusters; it is not installed. Source-based coastal concordance safely restores 138.30 km² in the isolated candidate, but **25 neighboring-source conflicts totaling 331.61 km² and 339.46 km² of unresolved old land** remain. The retained proof bundle and blocked products are in `data/retained-geographic-sources/namibia`; see `docs/NAMIBIA_REPAIR_MIGRATION.md`. No neighbor clipping, nearest-territory assignment or historical transfer silently closes those cases.

Fifteen macro-boundary conventions still need stronger physical/island evidence. Source omissions, marine-versus-land distinctions and coastline vintages also remain open. Grid coverage is a separate question from source completeness.

## Grid evidence and practical limits

`data/final-grid-resolution-review.json.gz` records every location at each candidate resolution. Resolution 10 has zero missing current locations and zero measured WGS84 relative-area errors above 25%; maximum error is approximately 22%. The permanent compact CPU ownership array is **232,467,128 bytes**, with a comparable GPU copy; compressed transport is **47,562,760 bytes**. All 58,116,782 decoded integer words were compared exactly.

`data/final-grid-rendering-review.json` records actual Chromium/SwiftShader WebGL checks and an explicitly simulated 4,096 texture limit. Those checks establish shader/addressing correctness and zero navigation ownership uploads for the tested assets. They do not establish physical mobile memory capacity or device frame rates. The approximately 521 MB observed JavaScript heap includes transient decoding. Zero grid IDs mean water **or source coverage gaps**, not proof of unowned land. See `docs/FINAL_GRID_ASSESSMENT.md`.

## Sustainable content work and future releases

The website/UI consumes the shared contract and stable API independently of record contents. Future names, attributes, people, events, places, armies, routes, artifacts and sourced relationships can be added through bounded imports without editing the interface or recompiling unchanged geography. Media has stable linked identities in separate object storage. The current service is bounded; eventual database partitioning and larger-media multipart transport must remain behind the same API. See `docs/HOSTED_STORAGE_ARCHITECTURE.md` and `docs/LUNA_DATA_HANDOFF.md`. Historical content should use sparse supported intervals, not 200 million location/year snapshots.
