# Geographic foundation milestone

The audit proceeds through continent → subcontinent → region → area → province → location. Each parent's extent is the union of member locations; the semantic review must assess that extent and every direct child. A boundary/source assessment cannot certify a branch whose children remain unresolved. Country profiles are a supporting source crosswalk, not the audit hierarchy.

Every active node is inventoried in `world-review.json`, with parent, children, source, reasons and separate semantic status. The browser's Coverage and review dialog exposes the entire tree, loading every province member on demand. No branch is omitted because examples elsewhere passed. `level_progress` counts pending reviews separately from source assessments. Explicit reviewed decisions require source evidence; current source assessments do not constitute worldwide semantic completion.

The geographic source audit covers all 252 reference-owner groups and crosswalks them to 201 source-policy profiles. Missing policies, source roles, coarse territories, tiny units and low-confidence parent matches remain open. These reference territories do not determine dated political ownership. Modern reference territories and their polities also have separate fields: dependencies and SARs use the source sovereignty relationship; indeterminate reference territories have unresolved ownership. Reference dates and dispute notes stay in attribute provenance.

This milestone corrects the general foreign-boundary-match rule: regional matching is constrained to each location's original source reference territory, before assigning named geography. It does not use the selected year's owner. Named local territories remain indivisible. Reparented identities and before/after links are recorded in `regional-membership-report.json`; replaced local identities retain original geometry and historical records in the database.

India's finer subdistrict source is adopted only where whole named units and bounded edge reconciliation cover the original district footprint. Units retaining less than 90% of their published source footprint are excluded. Incomplete source districts remain explicit review cases. Pakistan and Bhutan's evaluated finer sources fail the coverage guard and are not substituted. This is evidence-based adoption, not an attempt to achieve a target count.

The fixed-grid audit inventories every location. The current canonical grid represents 49,561 of 49,614 locations; 53 remain open. A territory without an interior cell is recorded as missing; no arbitrary neighboring cell is assigned to make the count pass. These cases require a documented correction: original source comparisons show that some disappear after disputed country-mask clipping and some already have incorrect or inadequate source geometry. A finer grid alone cannot repair those cases. Source-based consolidation or finer canonical resolution is appropriate only where the original geographic footprint supports it. Navigation continues to reuse the ownership assets. Representation and semantic completion remain separate publication scopes.

The macro-geography research inspected every current continent, subcontinent and region. `macro-corrections.json` records 713 changed location names or ancestor chains, 83 changed geographic groups, and 22 retired group records. Pacific archipelago memberships and residual island/coastal groups were corrected with sourced reference geography; canonical location footprints and IDs are unchanged. This does not close all provincial/local semantic reviews. The active hierarchy now has 49,614 locations, 5,220 provinces, 489 areas, 66 regions, 29 subcontinents and six continents.

`granularity-review-evidence.json` applies the same screening rubric to all 252 reference territories and 201 source profiles. The profile/territory crosswalk is explicit. It records every flagged location and nine actually inspected finer geometry candidates, with source-role, coverage and licensing blockers. Flags identify research work rather than automatically prove errors.

Prepared environmental evidence now contains 346,293 climate, biome and topography records for 49,596 locations with at least one reference. Sixteen source biome labels of “N/A” resolve to null with provenance; 49,280 known biome references remain. EarthEnv supplies authentic landform classes for 49,582 locations at its published resolution, with compilation/publication dates distinct from the 2026 display reference. None of these references silently fills ancient attributes. Settlement series contain 9,301 estimates on 582 separate settlement identities and do not supply location totals or ranks.

The immutable source archive retains 19,050 older location identities, original geometries and chains. A fresh database restores all nine original state records and six original historical records before adding examples, with explicit collision errors instead of record transfers. Cartographic replacement crosswalks have no invented historical effective year. Older source discrepancies remain documented.

## Reproduction

1. `npm run data:prepare` restores the existing pinned administrative/framework evidence, performs source refinements and constrained regional matching, checks small border units against their whole sourced parent, then runs the exhaustive structural/source audit and inventories every hierarchy branch.
2. `python scripts/attribute-sources.py` restores checksum-pinned environmental and settlement inputs.
3. `python scripts/prepare-ownership.py` uses bounded-memory, resumable disk checkpoints to derive dated ownership from Cliopatria and supported footprint overrides in the existing database. It never reassigns original imported direct records.
4. `python scripts/prepare-reference-attributes.py` prepares climate normals, potential natural biomes and settlement estimates; deduplicated references resolve only the selected date.
5. `python scripts/prepare-topography.py` followed by `python scripts/merge-reference-attributes.py` adds the independent sourced topography preparation.
6. `node scripts/audit-pixels.mjs` records coverage and pixel distortion for every active location.
7. `node scripts/stamp-prepared.mjs` verifies/stamps current footprint hashes for a metadata-only review performed during preparation; normal preparation stages stamp their captured starting hash automatically.
8. `python scripts/recheck-vegetation.py` retains a per-location receipt for precise WGS84 union coverage, including overlap between source biome classes. `python scripts/prepare-ownership-runtime.py` compiles bounded century assets that retain exact original intervals and dated provenance.
9. `node scripts/validate-prepared.mjs`, `python test/majority.py` and `python test/majority-cached.py` check prepared data and numerical edge cases. `npm run build:hosted` builds the Worker, fixed client assets and schema-only migrations and precedes `ATLAS_REQUIRE_PREPARED=1 ATLAS_REQUIRE_STATIC=1 node --test test/prepared-parity.test.mjs`, `npm test`, `npm run test:ui` and `npm run test:static`. These publication checks are separate from semantic review.

Outstanding semantic research remains visible. Province-sized local units and source city fragments still require sourced decisions where the current inventory flags them. Dated culture, religion, habitation, rank, population totals and historical names remain unknown without location-specific evidence. Settlement population estimates do not fill those gaps. Pixel losses and source omissions remain open rather than being certified by structural success.

The source-role research now covers every current region, area, province and location in `region-semantic-review.json`: 66 regions, 489 areas, 5,220 provinces and 49,614 locations, with 199 source URLs. These documented assessments and correction proposals do not approve unresolved geography. The full branch report is downloadable from Coverage.

The numerical ownership audit remeasured all location footprints and cached intersections using precise WGS84 area integration, verified candidate completeness against all 13,378 source geometries, and retained initial and corrected execution proofs. The resulting 6,834,664 dated intervals have 1,434,173 evidence rows. Exact runtime transport retains those intervals and passes source-record comparisons without changing their dates.
