# Geographic and persistent-record foundation milestone

This publication is a validated foundation milestone, not worldwide semantic completion.

## Delivered

- 49,614 active polygon locations have complete adjacent-tier reference chains: 5,220 provinces, 489 areas, 66 regions, 29 subcontinents and six continents. Antarctica is excluded. EU5 counts remain a scale reference, not quotas.
- All attributes resolve to a single whole-location value or explicit unknown, with source intervals, assignment methods and status. Historical political source polygons are evidence for location assignments rather than independent map fills.
- Precise WGS84 ownership preparation measures the entire applicable location land footprint, unions same-polity polygons and requires strictly more than half. Contradictory overlapping claims and no-majority cases stay unresolved. All locations were checked against all 13,378 source geometries; no positive-area candidates were omitted. The output has 6,834,664 exact dated intervals and 1,434,173 evidence tuples, with retained initial and corrected algorithm/source proofs.
- Timeline transport preserves exact source dates and evidence. It loads one relevant dated batch rather than the full reconstruction. Fixed location ownership and boundary assets are reused by navigation.
- Every current geographic branch is inventoried. Research covers all six continents and all 66 regions, 489 areas, 5,220 provinces and 49,614 locations, with explicit country-policy/reference-territory crosswalks and sourced correction proposals. Source assessments remain distinct from semantic approvals.
- The migration archive retains 19,050 earlier location IDs, original geometry and parent chains, all nine original state records and all six original history records. Unsupported transfer to new footprints is forbidden.
- Environmental references include dated climate normals, potential natural biomes and published topographic classes. Their dates and limitations remain explicit; settlement population series do not become location totals or ranks.
- The hosted record model uses stable graph identities, dated attributes/names, sourced relationships, immutable media metadata, transactional bounded imports and schema migrations. People, events, armies, routes, places and artifacts have supported entity kinds without fabricated production content. Media and source archives use independent object storage.

## Open work

- Global semantic review is not complete: 4,832 geographic groups remain open and source-assessed regional branches still need correction or supported exceptions. The current model still contains uneven source granularity, city fragments, coarse administrative remainders and inappropriate intermediate labels. The worldwide branch report records them; structural success does not close them.
- The canonical grid represents 49,561 locations. All 53 missing locations have representation results and original-source comparisons; 123 represented locations have high measured distortion. Some problems come from inadequate source geometry or reference country masks, so a finer grid alone will not solve them. No arbitrary neighboring cells were assigned to hide failures.
- Historical names, location population, primary culture/religion, habitation and rank are largely unsupported. Unknowns remain explicit across the 3000 BC–2026 AD timeline. Modern environmental references do not become ancient observations.
- The first hosted geographic parent registry is an undated reference snapshot. Future footprint/membership publication requires an explicit versioned geographic migration, successor crosswalks and regenerated prepared/grid hashes. The first hosted import API does not accept raw footprint replacements.
- The initial media upload endpoint is bounded at 20 MiB. Larger media needs multipart transport; stable media identities and links will remain unchanged.

Validation results and deployment/bootstrap receipts are recorded separately, so local preparation is not represented as successful production provisioning before it happens.

## Validation completed before provisioning

The full suite passed 64/64 tests without skips. Exhaustive prepared-data validation passed, and static/server resolution matched across 26 complete atlas comparisons at 13 dates with examples off/on. Development-browser checks passed 14/14. Hosted-client checks used a real local Worker; the historical South Dublin case matched all 368 canonical interior cells, inspector and legend. Navigation performed zero ownership compilations/uploads; the 390px mobile run had no overflow and a 3 ms render submission. Real local D1/R2 import, graph, date-boundary, rollback/idempotence and audio round-trip checks passed. All 438 catalog batches imported through the actual generated schema and service.

The final correction addition passed all 20 hosted database tests, the import-dialog tests, and real local D1/R2 supersession/withdrawal/history retrieval. Originals remain immutable and inspectable; media byte-range retrieval also passed.
