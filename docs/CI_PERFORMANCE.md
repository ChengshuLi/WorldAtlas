# CI performance and coverage

Use `coordination/engineering/ci-speed-1201-20261008-p1/` for the #1201 baseline,
complete test/workflow inventory and measurements. Timings describe actual runs,
not deadlines or a guarantee that later hosts are equally fast.

PR integration and the merge queue use the same `integrationProfile` and
`run-integration-tests.mjs`. Source-only geography requires its actual reservation
and exact owned paths. History uses its campaign directory. Known coordination
changes use the audited evidence profile. Unknown paths, changes outside those
scopes and rename origins fall back to full regression; invalid ownership or
incomplete API inventories reject rather than establish a focused proof.

The focused profile runs its complete audited test roster without application
installation, browsers, canonical product restoration or world computation.
The trusted handoff gate also runs historical evidence controls. Package selection
uses `.github/package-inputs.json` independently: only its declared inputs and
verification paths require rebuilding. Neither a fast job nor mechanical evidence
validation grants scientific approval. No new exclusions are introduced here.

Full regression discovers every `test/*.test.mjs` file and assigns it exactly once
to three shards. Packaged assets remain on shard 0, expensive database neighbors
on shard 1 and migrations on shard 2. The complete-world component corruption
controls run on shard 1 to avoid the previously overloaded migration shard. All
seven scenarios still execute against complete retained data. Unknown future tests
remain discovered; moving this control does not shift its ordinary neighbors.

Control fixture preparation only recomputes descriptors for altered payloads.
Reports and failed-trial receipts sharing those payloads are rebound together.
Unchanged descriptors remain original, including incorrect ones: preparation does
not repair them into apparent validity. `validate_science` authenticates every
actual file through the complete custody validator before each required semantic
rejection. The redundant preceding custody pass is removed. The separate positive
world test remains uncached and unchanged; the existing narrowly input-keyed
component reconstruction cache in the adverse controls is unchanged. Actual
cache-entry controls exercise unchanged hits, changed feature identity/roster,
properties/geometry, blocked-tile identity/bounds and scope bounds. A fresh setup
with a different counted kernel recomputes the same inputs; teardown deletes the
old cache. These bounded controls test caching, not geographic reconstruction.

The integration runner streams stdout/stderr while tests run, retains a bounded
TAP tail and enforces the existing 64 MiB transcript limit and zero-skips condition.
Failures retain their exit status. Every terminal result cleans remaining owned
process-group descendants on POSIX with escalation; successful orphaned work
rejects instead of claiming completion. Cancellation also reaches that group; it does not kill unrelated
workers. Scientific test wrappers can still buffer their own subprocess output;
the selected file list identifies them before execution, and their final timings
remain in TAP. More granular inner progress is a separate optimization.

Before optimizing another path, separate waiting, checkout, installation,
restoration, build and test time. Keep actual cold/setup costs in hosted comparisons.
A cache is not a substitute for authenticated inputs, current execution or exact-tree
review. Do not drop exhaustive scientific proofs or repeat a running job merely
because it is slow. Provider/database/deployment workflows require their normal
operator authority; performance investigation does not authorize live writes.

Local profiling uses a managed slot, bounded temporary fixtures and actual task
memory observations. A geography packet's percentage threshold is not a universal
CI admission rule. Recheck the shared storage budget before generation; preserve
necessary evidence and release the completed owned slot after verified merge.
