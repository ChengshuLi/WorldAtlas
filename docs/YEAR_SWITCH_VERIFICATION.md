# Year-switch performance verification

The compact map reader opts into `GET /api/map/snapshot?year=1950&limit=1000&evidence_only=1`. This pages only eligible identities with selected-year attribute/name evidence, **including retired evidence**. Withdrawal-only subjects must remain in the stream so prepared assets cannot resurrect their claims. Complete winning fields, names, source dictionaries, withdrawals, revision checks and response limits are unchanged. Default requests still enumerate all eligible map identities for backward compatibility. Geometry, membership and lifetimes come from the separate pinned geographic release and dated-geography streams, not scalar evidence identities. An older Worker may ignore the optional parameter and return the original complete stream.

`scripts/benchmark-live-year-switch.mjs` measures production through the documented private Sites header on a fixed-origin, GET-only localhost proxy. Supply the credential through its hidden TTY stdin JSON input; never put it in arguments, environment dumps, logs, Git or browser headers. Invoke with the production origin, an absolute receipt path and a phase label. It retains credential-free request latency/byte summaries, Chromium CPU metrics, canvas ownership counters, a compressed CPU trace and a screenshot. Successful completion writes `completed:true`; partial receipts do not establish a passing run.

The fresh browser-context measurement describes a cold browser cache, not a proven Neon idle wake-up. Nearby, distant, repeated and rapid selections measure selection through complete visible map state plus two animation frames. Software rendering and the cloud proxy route are documented test conditions, not physical-device evidence. API request timing includes network, Worker and database execution; it cannot independently distinguish their contributions. The proxy buffers each response, and its upstream reads may complete after Chromium cancels an obsolete request. Rapid-switch results therefore establish browser latest-selection behavior, not provider cancellation. No trace includes the bypass credential.

The initial production reproduction on Site 21 showed 57 sequential scalar pages per year, mostly empty identity envelopes, plus two subsequent dated-geography stream reads. Before/after receipts and publication evidence belong to the linked issue and the job's own engineering evidence directory. Performance targets and remaining cold-start limitations must be assessed against the matching deployed source. Source tests alone do not establish production latency, all-mode/profile coverage or completion of the issue.
