# Location attribute contract

A location is an indivisible polygon territory. A selected year resolves one scalar value (or explicit unknown) per attribute. Political, cultural, religious and environmental modes use that record for the entire location. Higher geographic boundaries follow adjacent locations' resolved parent membership; political boundaries follow adjacent owners.

`attribute_entities` gives owners, cultures and religions stable IDs and reference names. Imports may supply a dated display name alongside the same category ID. `attribute_records` imports contain `id`, `location_id`, `attribute`, `value`, `category_id` required for non-null owner/culture/religion, `valid_from`, `valid_to`, `method`, `status`, `source`, optional `is_example` and object-valued `metadata`. Values are nonempty text or null, except population, which is a nonnegative safe integer or null. Unknown values have no category ID. Dates use inclusive starts, exclusive ends, no year zero, and 2027 as the final end sentinel; records must fit a known entity lifetime. Field records cannot overlap within the same method/evidence class. Evidence is append-only: SQL updates and deletes are rejected. Category identities are immutable; changing display names uses dated records with the same ID. Insert triggers also enforce this contract on existing databases without rewriting archived evidence.

Resolution order is field-specific direct evidence, dated entity attribute snapshots, legacy complete location snapshots, derived assignments, references, estimates, then explicitly enabled examples. An explicit null is evidence for unknown, not permission to silently substitute a lower-priority claim. Modern ownership reference applies only to 2026. Field-specific evidence does not erase another independently supported field. Legacy complete snapshots retain their complete-snapshot semantics.

Historical ownership preparation measures each location's whole land footprint with WGS84 ellipsoidal area. Longitude rings are normalized across the antimeridian; linear geographic edges are densified for consistent area partitions. Uncovered land stays in the denominator. Same-polity polygons are unioned. More than 50% (with a conservative 1e-8 share numerical tolerance) wins only when competing claims do not contradict it. Competing overlaps below 1e-6 of the whole footprint are treated as numerical slivers; retained shares use 12 decimals. Ties, missing majorities and contradictory overlapping claims resolve to null with status and shares retained. Applicable sourced footprint overrides participate. Inputs and algorithm hashes invalidate preparation caches.

Cliopatria remains evidence, rather than a second fill surface. Geographic changes archive source IDs, geometry and history. Derived records on replaced footprints must be regenerated; direct demographic records are not redistributed without evidence.

Climate records describe published normal periods, not annual weather. The modern climate reference explicitly cites its 1991–2020 normal. Vegetation biome references describe potential natural vegetation; observed cropland remains unsupported until a land-cover product is aggregated. Natural Earth population series describe settlement estimates/projections at source dates, in thousands converted to persons. Settlement values never become location totals, ranks or founding dates.

Normal Political mode exposes no independent political fill geometry. `/api/snapshot?year=1444&source_evidence=1` provides the original source footprints for evidence inspection. Prepared intervals retain active source record IDs, competing shares, coverage and the winner’s dated source label; the category identity remains unchanged when its label changes.
