Data sources for the current map

Partial source summary. These are inputs identified for the currently displayed Iceland-boundary grid. The full source and decision inventory has not yet been reconciled. This grid is the existing composition, not the separate end-to-end rerun.

Physical land and water

  • OpenStreetMap contributors: a land-polygons mirror snapshot from 3 November 2026. The land shapefile used for the candidate has SHA-256 e2258f3e849f8101cd44cea0f7c6e1ae5b476ef11f84e053af8a29f6cb82ffc3. It is an approximate replacement for the older baseline source, not that historical source.
  • Overture Maps Foundation, Base water release 2026-10-21.0: 32 input shards were processed. The candidate water-mask policy selects OSM-sourced polygon features and excludes ocean/sea classes and physical/ocean subtypes.

Sea and ocean boundaries

  • SeaVoX Salt and Fresh Water Body Gazetteer v19, British Oceanographic Data Centre (2023), via Marine Regions, CC BY 4.0. Selected sea-area polygons were rasterized and adapted for named-water assignments, including the Gulf of Carpentaria. The source archive used by the recorded Gulf assignment has SHA-256 78a7983940aa73989642f2b95f9261c07fc234bf7f8cd14e0dff96bb90ce7e0a.
  • International Hydrographic Organization S-130 Global Dataset, Edition 1.0.0 (July 2026): source lines M.1504 and M.1505 informed the selected Iceland-connected rhumb routes. Archive SHA-256: 44997a24a4fe83256cce1ef2b28588f46c9c2b7f1036a78bdb39283c5c0a76de. The dataset-specific reuse status is still under review.

What the checks establish

The displayed grid has 131,072 columns and 54,614 rows. Its combined SHA-256 is 4a34371c8f508380dde9b9b54d1edd642f217252f17b40885c86b2b192898dbd, calculated over uncompressed little-endian u32 row offsets followed by uncompressed little-endian u32 runs. This identifies the displayed grid bytes, not the source inventory or the correctness of geographic decisions.

The Iceland update reused earlier closed-water classifications; those classifications were not revalidated by that update. The remaining individual source records and geographic decision lineage are not yet fully enumerated here.

The historical V7 source file documents the older V7 release and is not the source inventory for this grid.
